任务工作区适合需要动手的工作。每条会话由一个 Agent 执行，聊天记录和文件、终端、网页可以放在同一屏。

## 新建与继续

桌面从「项目」点「新建会话」，选 Agent、模型和设备，带着第一条要求发送。临时任务可以保留「未选择项目」；处理已有材料时，进入对应[项目](/projects)，从具体文件夹开始。

回到侧栏里的原会话，直接补充要求。新建任务发送首句后就开始执行；分叉出来的会话继承上下文，再给它一句新要求才继续工作。

新任务可选的模式中，「通用」用聊天和过程摘要交流，「编程」展示 Agent 的终端界面。两者都能做工作，可选模式以当前 Agent 和设备为准。

## 看过程，打开结果

思考和连续工具操作会汇成一行摘要，点开能逐条查看。文件链接可以打开到相应位置；支持预览的文件可直接看成品。

Agent 执行时，还可以补充下一条消息。排队中的消息在输入框附近显示，可按界面提供的操作编辑、删除或调整。

## 修改要求、分叉和侧边任务

| 操作 | 适合什么、执行后怎样 |
|---|---|
| 原会话继续发送 | 接着做、补要求，保留当前上下文 |
| 编辑旧要求 | 支持的消息下方点编辑再发送。对话回到该句之前，后续对话退出有效上下文；文件和外部操作不会撤销 |
| 会话分叉 | 保留原思路，再试另一条路。继承上下文后分别继续，工作目录仍可能相同 |
| + → 侧边任务 | 临时分出去查一件事。从当前上下文分支，退出应用后消失 |

消息编辑只在当前 Agent 和历史记录支持时开放，工作中或还有排队项时可能不可用。需要保留某份结果时先另存；分叉上下文也不会复制正在运行的终端。

*界面动画：在任务旁边打开结果，再继续提修改意见。视频没有声音。*

点「+」添加文件、终端、浏览器或已启用的 App。需要同时看两页时，在页签菜单中选择向右或向下分屏，也可以把页签拖到内容区边缘。

一条会话里的并排始终显示两页。再开一页时，聊天保留，新页面替换另一侧。页签之间的「拆开」表示取消并排，之后不再自动分屏；只关掉其中一页，下次仍可以自动并排。

要同时看两条独立会话，可以把会话拖到内容区边缘。关闭 App 页签只收起页面；停用能力在 [App 管理](/apps)里操作。

## 结束与归档

完成后可以归档会话：它从列表隐藏，正在运行的 Agent 会停止，内容不会因此删除。操作后可以撤销；之后也能从会话历史恢复。

只想中断当前一轮，用停止；还要让它继续执行时，保留会话。
