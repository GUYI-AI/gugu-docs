任务工作区适合需要动手的工作。每条任务由一个 Agent 执行，聊天记录和文件、终端、网页可以放在同一屏。

## 新建与继续

桌面点最左栏的「消息」，在「项目」页签点「新建任务」。选引擎、模型和设备，带着第一条要求发送。临时任务可以保留「未选择项目」，它会列在侧栏的「任务」分区。处理已有材料时，点项目行上的「+」在那个[项目](/projects)里新建，或从项目里的具体文件夹开始。

> 把这份实验结果整理成表格，标出缺失项。先别修改原始数据，把结果另存为 Markdown。

回到侧栏里的原任务，直接补充要求。也可以按 ⌘O（Windows、Linux 上是 Ctrl+O）搜索任务名跳过去。新建任务发送首句后就开始执行；Fork 出来的任务继承上下文，再给它一句新要求才继续工作。

## 看过程，打开结果

思考和连续工具操作会汇成一行摘要，点开能逐条查看。文件链接可以打开到相应位置；支持预览的文件可直接看成品。

Agent 执行时，还可以补充下一条消息。排队中的消息在输入框附近显示，可按界面提供的操作编辑、删除或调整。

## 修改要求、Fork 和侧边聊天

| 操作 | 适合什么、执行后怎样 |
|---|---|
| 原任务继续发送 | 接着做、补要求，保留当前上下文 |
| 编辑旧要求 | 支持的消息下方点「编辑消息」再发送。对话回到该句之前，后续对话退出有效上下文；文件和外部操作不会撤销 |
| 侧栏任务右键 →「Fork 会话」 | 保留原思路，再试另一条路。继承上下文后分别继续，工作目录仍可能相同 |
| 页签栏「+」→「侧边聊天」 | 临时分出去查一件事。从当前上下文分支，退出应用后消失。需要本机项目，且引擎支持分叉 |

消息编辑只在当前 Agent 和历史记录支持时开放，工作中或还有排队项时可能不可用。需要保留某份结果时先另存；分叉上下文也不会复制正在运行的终端。

点「+」添加文件、终端、浏览器或已启用的 App。需要同时看两页时，在页签菜单中选择「向右分」或「向下分」，也可以把页签拖到内容区边缘。

一条任务里的并排始终显示两页。再开一页时，聊天保留，新页面替换另一侧。页签之间的「拆开」表示取消并排，之后不再自动分屏；只关掉其中一页，下次仍可以自动并排。

## 同屏看多个工作区

把侧栏里的另一条任务拖到主区边缘，可以分出独立工作块。每块有自己的任务，可以分别查看和操作；把分界拖宽，给当前工作留足空间。

多条任务拼成的布局会作为一组保留，切到别的任务后可再回来。任务内部的双页并排仍由同一条页签条管理，和多个独立工作块分别操作。关闭 App 页签只收起页面；左栏 App 图标右键选「退出」才结束它，停用能力在 [App 管理](/apps)里操作。

## 结束与归档

完成后可以归档任务：它从列表隐藏，正在运行的 Agent 会停止，内容不会因此删除。操作后可以撤销；之后也能在「项目」页签的「会话历史」里找到它，点「恢复」放回列表。

只想中断当前一轮，用停止；还要让它继续执行时，保留任务。
