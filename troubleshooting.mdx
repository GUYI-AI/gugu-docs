---
title: "遇到问题"
description: "按实际提示检查设备、Agent、模型和 App，让原来的工作继续。"
---

先记下提示、发生时间、版本，以及任务在哪台设备上。已有结果的任务，重试前先看文件和上一轮记录。

<AccordionGroup>
  <Accordion title="Agent 没有回复">
    先看设备是否在线、会话有没有正在执行的工作，再看是否出现登录、网络或额度提示。

    群里的被动 Agent 需要点名或回复它；主动 Agent 也可能判断这句无需回答。要它执行，明确 `@` 它并写清任务。
  </Accordion>
  <Accordion title="创建任务时选不了 Agent">
    在资源库检查安装状态，按提示安装。需要厂商登录的，在订阅页完成登录，或选择当前可用的咕咕模型。

    另一台机器上的任务，需要在那台机器具备对应 Agent；本机装过不代表远程也装好了。
  </Accordion>
  <Accordion title="模型提示额度不足或需要升级">
    核对选的是自己的模型还是咕咕提供的模型。前者检查对应厂商账号；后者检查咕咕会员权益和积分。

    不同来源的额度分别计算。查看用量失败时，先刷新或修复连接，不要把未知读数当成零。
  </Accordion>
  <Accordion title="App 装好了，Agent 还是不能用">
    到 App 页检查它是否启用、是否允许这位 Agent 使用，以及应用配置是否完整。

    操作电脑还需要 Computer Use 启用和系统权限；访问外部服务需要有效账号授权。连接刚改变时，重开普通任务会话再试。
  </Accordion>
  <Accordion title="另一台设备的文件打不开">
    检查文件实际在哪台机器、设备是否在线。咕咕共享项目和对话，文件夹内容不会自动同步。

    给其他人或另一台设备交付，用附件、群文件夹或可访问的仓库，不只给本地路径。
  </Accordion>
  <Accordion title="个人助理读不到任务或记忆">
    按页面的连接或读取错误重试，并检查助理所在设备。读不到不代表数据已删除。

    先恢复连接，再看原来的任务；不要为了解决读取问题关闭并重新开通助理，关闭会清除页面确认框中列出的内容。
  </Accordion>
  <Accordion title="收不到邮箱验证码">
    检查邮箱拼写和垃圾邮件，等页面允许后重新发送。已有账号继续用原邮箱登录。
  </Accordion>
  <Accordion title="界面和教程不一样">
    在设置的关于页核对版本。本文档按当前 Beta 整理，正式版可能尚未包含部分新功能。

    更新后仍有差异，从设置的关于页提交反馈，附版本、设备、简短复现步骤和截图；不要附验证码或密钥。
  </Accordion>
</AccordionGroup>

## 重试时说清从哪里继续

> 上次已经生成了结果表，但还没做图。先检查现有文件，只继续画图，保留原始数据。

如果某轮已执行外部操作，先确认结果再重试。工具成功、正在运行和任务交付分别表示不同阶段。
