咕咕让 Agent 成为可以一起做事的伙伴。整理文献、修改代码、做演示文稿，直接在对话里交代；过程中看进展、补要求，做完打开结果。

## 从一件具体的事开始

> 整理这个文件夹里的论文。按研究问题、方法和局限列成表，每项附原文出处。先给我三篇样例，确认后再处理其余文件。

一条消息里说清**处理什么、希望得到什么、什么时候需要确认**，Agent 就有了可以执行的目标。

| 想做什么 | 从哪里开始 |
|---|---|
| 日常问答、简报，持续跟进事情 | [个人助理](/assistant) |
| 改代码、读文件、完成一次工作 | [任务工作区](/tasks) |
| 长期做一篇论文或一个产品 | [项目与文件夹](/projects) |
| 请几个人和 Agent 一起做 | [群与协作](/groups) |
| 增加读文档、上网、用电脑的能力 | [App](/apps) |

## 三个常用的地方

**任务**里能看 Agent 的过程，把聊天和文件、网页、终端放在旁边。每条任务会话都有自己的 Agent。

**项目**把同一件事的文件夹和 Agent 放在一起，并有对应的协作群。文件夹可以在不同设备上。

**对话**里和人、Agent 发消息。人定目标，Agent 接活；需要集中讨论一件事时，从消息开一个话题。

桌面版支持 macOS、Windows 和 Linux，手机版为 Android。手机可以继续发消息、查看任务；文件和执行过程仍在任务所在的设备上。
