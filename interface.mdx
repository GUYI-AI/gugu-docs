第一次打开咕咕，先认清最左栏。几乎所有入口都从这一栏出发。

<Note>本页对应当前 Beta 的桌面版和 Android 版。正式版可能有所不同，见[更新与版本](/settings#更新与版本)。</Note>

## 桌面最左栏

从上到下依次是：

| 图标 | 点了去哪 |
|---|---|
| 咕咕头像 | 你的[个人助理](/assistant)。还没开通时，头像右下角带「+」，悬停显示「开通你的咕咕」等提示 |
| 「消息」 | 项目、任务、和人或 Agent 的对话都在这里。macOS 上可按 ⌘1 |
| 「联系人」 | 找人、加好友、管理自己的 Agent，见[通讯录与分享](/contacts)。macOS 上可按 ⌘2 |
| 「资源库」 | 存常用的「提示词」，管理「智能体」和「集成」 |
| 「App」 | 已安装的 App。右键列出可打开的 App |
| App 图标 | 固定到左栏的 App，可拖动排序。右键可选「打开」「在新窗口打开」「从左栏移走」「退出」，见 [App](/apps) |
| 「帮助与导览」 | 重看界面导览 |
| 「设置」 | 账号、模型、额度和偏好，见[设置](/settings)。macOS 上也可按 ⌘, |

鼠标停在图标上会显示名字。

## 「消息」里的两个页签

点「消息」，侧栏顶部是「项目 | 对话」两个页签。页签上的数字是未读数。

**「项目」页签**从上到下是：

- 「新建任务」：打开新建任务页，见[任务工作区](/tasks)。
- 「会话历史」：查找过去的任务，包括已归档的；点「恢复」放回列表。
- 「已安排」：查看全部定时工作，见[定时安排](/schedules)。
- 「置顶」：置顶的任务。
- 「项目」：每个项目一行。标题旁的「添加项目」用来新建或加入文件夹；项目行上的「+」在这个项目里新建任务，见[项目与文件夹](/projects)。
- 「任务」：不属于任何项目的任务。

新账号的项目列表里有一个标着「示例」的「周末去杭州」。它只能看，不能在里面发消息。

**「对话」页签**列出你和人、和 Agent 的聊天以及群聊。顶部有「新建任务」「新建群聊」「添加联系人」三行。和别人协作要在这里新建群聊，详见[聊天与消息](/chat)和[群与协作](/groups)。

### 合在一起显示

想在一列里同时看项目和对话，点侧栏右上的「左侧栏显示方式」，或在侧栏空白处右键，选「项目和对话合在一起」。合在一起时，「对话」分区排在项目下面，分区头的「+」提供「新建群聊」「添加联系人」。选「项目和对话分开」恢复两个页签。

## 搜索和命令

侧栏顶部的「搜索...」是快速切换入口，也可以按 ⌘O（Windows、Linux 上是 Ctrl+O）。输入名字，就能跳到任务、群、项目和联系人。

在搜索框里先输入 `>`，就切换到命令。

## 新建 Agent

新建一条任务时就会有一个新的 Agent。另外还有几个入口直接新建 Agent：

- 「联系人」里设备分组上的「新建 Agent」。
- 群成员列表里的「新建 Agent 并加入本群」，建好就在这个群里。
- Windows 窗口顶部菜单「文件」→「新建 Agent」。

Agent 的设置和管理见 [引擎与 Agent](/agents)。

## 群聊顶部

打开一个群，顶部右侧从左到右是：

- 固定到本群的 App 图标，以及「群 Apps」：在这个群里打开 App，或把 App 固定到本群头栏。
- 「在对话中搜索」。
- 「群文件夹」：这个群共用的文件，见[群文件夹](/folder)。私聊里叫「文件夹」。
- 「成员列表」：成员、公告和群设置。
- 「更多操作」：里面有本群的话题列表和群信息。

置顶的话题显示在消息区上方的一排页签里，和「群聊」并列，点一下就切过去。怎样开话题、谁会收到通知，见[话题](/topics)。

项目群只有你和你的 Agent。要与其他人协作，在「对话」里新建群聊。

## 手机布局

手机底部是「消息」和「伙伴」两栏，左右滑动也能切换。

- **我的**：点「消息」或「伙伴」页左上角的自己头像。
- **个人助理**：开通后，它排在「消息」列表最上面一行。点进去是一整页，在「聊天」「动态」「任务」「记忆」「资料」之间切换。
- 群和任务的手机用法见[用手机看管任务](/mobile)。

## 重看导览

桌面版第一次登录走完引导后，会问「要不要带你看看？」。选「带我看看（1 分钟）」，会依次指出咕咕、项目、对话、联系人、资源库、App 和设置。选「直接开始」跳过。

之后想重看，点最左栏的「帮助与导览」，选「从头开始导览」。没看完就跳过或退出的，菜单里还有「继续导览」，从上次那一步接着看。
