# 咕咕用户文档

文档面向产品用户，说明任务、项目、个人助理、App、协作、设备和模型用法。产品事实取自产品仓 dev 的界面文案、界面代码及真实操作；本节点只约束文档职责，不另定义产品预期。

- 每项功能须可追溯，Beta 功能标明版本范围，设计稿不能作为已交付的证明。
- 既有九篇正文的 URL 保持可用。新增页面进入 docs.json 导航。
- 页面包括用途、必要步骤和具体示例，正文不写内部术语和设计沿革。
- 入门教程提供可复制材料或练习包、明确产物和检查点；涉及新任务路径时，区分页面验证、源码核对与匹配版本的实际操作。
- 价格和在售模型引用当前账户或官网页面，不在文档内维护另一份易过时的数据。
- 视频使用原生控件，配封面、字幕及文字步骤，按需加载；动画、实际截图串联的图解和连续录屏分别注明来源与形式。
- 构建、内链与实际桌面和手机阅读均需验证。用户审阅的是可运行预览；未经合并发布不得称已上线。

维护入口为 AGENTS.md、README.md 和 videos/README.md。
