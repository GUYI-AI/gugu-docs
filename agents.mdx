新建任务时，先分清三个选择。

| 选择 | 决定什么 |
| --- | --- |
| 引擎 | 用哪个执行工具，如 Codex、Claude Code、OpenCode |
| 模型 | 用哪个模型，记在自己的厂商账户还是咕咕积分上 |
| 设备与文件夹 | 在哪里读文件和运行程序 |

Agent 是为你工作的执行者，也可以有自己的联系人身份参与群聊。引擎决定怎样执行，模型提供推理能力；同一种引擎可以使用不同模型。

## 安装与选择引擎

在「资源库」查看安装情况。创建任务时，选择器也会区分已安装和需要安装的引擎，按提示完成安装。

当前接入的选择包括 Codex、Claude Code、Qwen Code、GitHub Copilot、OpenCode、Hermes Agent、MiMo Code、CodeBuddy Code 和 Pi 等。各家支持的展示模式、登录方式和模型连接不同，可用范围以当前版本的资源库和选择器为准。

第一次先用一种已可用的引擎完成小任务，再按工作需要比较其他选择。不必一次安装全部引擎。

## 自己的订阅与咕咕模型

已有厂商订阅或 API 连接，在「设置 → 订阅」管理。选择模型时，自己的厂商模型和咕咕提供、按积分计费的模型分别显示。

咕咕提供的模型由咕咕统一接入，不要求用户自行配置网关地址。能否与当前引擎、模式配合，以选择器说明为准；部分引擎仍可能需要自己的账号前置条件。

模型和在售权益会更新，文档不另存完整模型和价格名单。选择和计费细节见[模型、订阅与积分](/models)。

## 新建一位 Agent

这些入口都会打开同一个新建页：

- 「对话」列表顶部的「新建 Agent」。
- 「联系人」列表设备分组旁的「新建 Agent」按钮。还没有 Agent 时，空列表里也有这个按钮。
- Windows 窗口顶部「文件」菜单里的「新建 Agent」。
- 群里打开「群成员」，选「新建 Agent 并加入本群」。新 Agent 建好后直接进这个群。

写下第一句要求，选好引擎、模型和设备再发送。发送后它开始工作，后续步骤见[任务工作区](/tasks)。

## 调整一位 Agent

在「联系人」里选中自己的 Agent，打开它的设置。左侧按页签分开：

| 页签 | 用途 |
|---|---|
| 资料 | 名称、头像、简介，以及「暂停 Agent」 |
| 形象 | 只有个人助理有这一页 |
| 分享 | 「转发给联系人」或「对外分享」，见[通讯录与分享](/contacts) |
| 定时任务 | 让它按时间自动做事，见[定时安排](/schedules) |
| AI 模型 | 换模型，生效方式按页面说明 |

打开「暂停 Agent」后，它只回应你和它的私聊。关掉开关即恢复。

## 继续同一位 Agent 的工作

任务保留要求、过程和回复。回到原任务继续补要求，无需重新介绍全部背景。

任务中的 Agent 也能作为联系人参与项目群。希望它继续做某件事，点名或回复它的消息，说明希望完成的结果。

在线说明运行设备保持连接；工作状态来自执行过程。连接失败、登录失效和额度不足分别按界面提示处理。一个工具执行成功，只说明那一步完成，最终仍需检查交付结果。

打开历史工作见[任务工作区](/tasks)，手机看进展见[手机端](/mobile)。
