新建任务时，先分清三个选择。

| 选择 | 决定什么 | 例子 |
|---|---|---|
| Agent | 用哪个工具执行工作 | Codex、Claude Code、OpenCode |
| 模型 | 这次用哪个模型、记在哪个账户上 | 自己的订阅，或按积分计费的咕咕模型 |
| 设备与文件夹 | 在哪里读文件、运行程序 | 自己的电脑，或已连接的服务器 |

同一种 Agent 可以配不同模型。模型能否使用，以当前 Agent 的选择器和账户权益为准。

## 安装与登录

在「资源库」查看各家 Agent 的安装情况。新建会话的选择器也会区分已安装和尚未安装的项目；按提示安装后再开工。

常用选择包括 Codex、Claude Code、Qwen Code、OpenCode、Pi、GitHub Copilot 和 Hermes Agent。可用名单随版本更新，以资源库为准。

已有厂商订阅或 API 连接，在「设置 → 订阅」管理。咕咕提供的模型使用咕咕账户额度，无需再登录对应厂商。

<Tip>第一次先选一种 Agent 完成小任务。之后再按任务需要比较不同 Agent，无需一次装齐。</Tip>

## 会话就是这位 Agent 的工作记录

任务里的会话保存交代过的要求、过程和回复。回到同一条会话就能继续补要求，不必每次重新介绍。

一条任务会话也能作为联系人参与项目群。想让它继续某件事，可以点名或回复它的消息，说明希望它接着做什么。

## 看懂状态

在线说明运行设备保持连接；工作中的提示来自实际执行过程。连接失败、登录失效和额度不足会分别显示原因。

一个工具执行成功，只说明这一步完成。是否交付仍要看 Agent 的结果和实际文件。

模型与计费的细节见[模型、订阅与积分](/models)，打开历史工作见[任务工作区](/tasks)。
