title: "群文件夹"

---

每个群有「群文件夹」，私聊里叫「文件夹」。话题与来源聊天共用同一个文件夹。人和 Agent 读写的是同一份文件；几个人和 Agent 同时改同一个文件，各自的改动都会保留。

群文件夹随咕咕预装，不需要从市场安装。

## 打开文件夹

- 群聊页头的文件夹图标「群文件夹」。手机上收在「更多操作」里。
- 群里页签行末尾的「+」，选文件夹。
- 聊天里的 Markdown 和 JSON 文件，可以直接用文件夹打开。

## 管理文件

「新建」里有「新建文档」和「新建文件夹」，旁边是「上传」。上传重名文件时，可以选「两个都留」「替换原来的」或「不要新传的」。

右键一个文件（手机上长按），可以打开、下载、「复制链接」「在聊天中定位」「详情」「改名」「移动到…」「删除」，或「用别的 App 打开」。「在聊天中定位」会跳回发出这份文件的那条消息。

列表可以按文件名筛选，按「最近」「名称」「大小」排序，按类型只看「文档」「图片和视频」或「其他」，也能在「列表」和「网格」之间切换。

## 一次处理多个文件

点「选择」，勾选文件，或用「全选」。底部可以批量「下载」「设为临时」「一直保留」，也能「在聊天中定位」逐条跳到来源消息。

## 文件保留多久

| 保留方式 | 结果 |
|---|---|
| 「临时」 | 到期清除云端副本。期限按上传者在「设置 → 设备」里「文件存储」的设置 |
| 「一直保留」 | 保留到有人删除 |

只有上传这份文件的人能改它的保留方式。

项目群的文件可以只留在绑定项目的机器上，有人打开时才上传一份。那台机器离线时，文件要等它上线才能打开。

## 读写文档

Markdown 文档有三种显示：「阅读」「编辑」「对照」，默认先阅读。

阅读时把鼠标移到一段上，会出现段落菜单：

- 「引用到聊天」：把这段带着行号引用进输入框。
- 「加入待引用」：先记下，凑齐几处再一起引用。
- 「复制这一段的链接」：别人点开直接定位到这几行。
- 「在源码里定位」：切到源码并标出这几行。

阅读页里勾选待办，源码里那一行的 `[ ]` 会同步变成 `[x]`。编辑时选中文字，可以加粗、斜体、标为代码或加链接。

空文档会提示「开始写」或「请 agent 起草」。后者把起草请求和这份文件一起放进输入框，补充内容后发给 Agent。

JSON 文件可以直接查看和修改，改完选「应用」或「放弃」。

## 交给 Agent

允许使用这个 App 的 Agent 可以列出、新建、读取、修改和删除群文件夹里的文件。交代时写清文件名和要改的部分。

> 请更新群文件夹中的 meeting-outline.md，只改第二部分，保留引用，再把结果回复到这条消息。

标注过的图片，也能在「编辑图片」里「存进群文件夹」，见[聊天与消息](/chat#在图片上标注)。
