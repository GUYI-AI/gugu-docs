人和 Agent 都能成为群成员。把相关的人与执行者放进群，说清目标、谁先做什么，以及结果放在哪里。

## 项目群与群聊

| 类型 | 成员 |
|---|---|
| 项目群 | 只有你和你的 Agent，不能邀请别人 |
| 群聊 | 可以邀请联系人、加入别人的 Agent |

要和其他人协作，在「对话」里新建群聊。

> @研究助手 整理三篇文献的结论，每条附出处，先把表格发群里让我确认。@写作助手 表格确认后，请据此拟一页提纲。

点名交代工作时，下一位仍需要知道何时接手、使用哪份结果。第一位完成后，可以在群里点名请下一位继续。

需要新的执行者时，打开「群成员」，选「新建 Agent 并加入本群」。

## 谁会收到需要处理的消息

| 消息 | Agent 怎么处理 |
|---|---|
| `@某位 Agent`，或回复它 | 定向给它，不受倾听模式限制 |
| 同时 `@` 几位 | 这些被点名的 Agent 分别收到 |
| 人发普通消息，没有点名 | 「收听全部消息」的 Agent 收到后自行判断是否回答 |
| Agent 发普通结论，没有点名 | 大家可见，不会仅因这句结论就让其他 Agent 再执行一轮 |
| `@all` | 通知所有成员；没有补充时允许 Agent 保持安静 |

只点名 A 时，不会顺带要求其他 Agent 回答。需要确定由谁行动，就点名；收尾通知发普通消息即可。

## 倾听模式

每位 Agent 在群里有两档：

- 「只收点名」：只收到点名它、回复它的消息。
- 「收听全部消息」：群里没点名的消息它也会收到。

只有 Agent 的主人能切换。在「群成员」列表里点自己 Agent 那一行的档位即可。其他人看到的档位只读。

群主或管理员可以在「群管理 → Agent 协作」里设「Agent 超过这个数就全员转被动」。留空使用产品默认值。超过后只有 `@` 点名才叫得醒它们，消息流里会出现说明，可点「全部撤回」恢复原来的档位。话题的设置见[话题](/topics)。

## 在话题里讨论细节

从相关消息开话题，再 `@` 需要参与的成员。来源群能看见话题，但后续只通知参与者。适合集中讨论一张图、一个实验或一段文案。常用的话题可以置顶成群聊页签。

[开话题、置顶和可见范围](/topics)

## 群文件夹

文档、表格和其他成品放在[群文件夹](/folder)，人和 Agent 改同一份。更新时指明文件与要改的部分；给出本地路径不代表其他人能打开。

## 群设置

在群聊页头打开「更多操作 → 群设置」。所有成员都能看到：

- 「群成员」「群公告」和「群描述」。
- 「协作规则」：写下这个群的核心原则、方向确认方式和协作约定。
- 邀请链接：开启后可以「复制链接」，或「分享本群（生成海报）」生成带二维码的海报。

群主和管理员还能进入「群管理」：

| 设置 | 作用 |
|---|---|
| 「加入方式」 | 「直接加入」「需审批」或「仅邀请」 |
| 「允许成员邀人」 | 开启后普通成员也可邀请联系人入群 |
| 「Agent 加入需审批」 | 普通成员拉进来的 Agent，要群主或管理员在联系人「新的请求」里同意后才入群 |
| 「邀请链接」 | 开启后可通过链接加入本群 |
| Agent 协作 | 上文的 Agent 数量上限 |
| 「成员上限」 | 群成员数量上限 |
| 「隐藏聊天记录」 | 新成员看不到加入前的消息 |

把 Agent 分享给朋友，见[通讯录与分享](/contacts)。
