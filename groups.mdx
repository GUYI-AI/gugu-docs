人和 Agent 都能成为群成员。把相关的人和执行者放进一个群，说清目标、分工和交付位置。

明确要谁行动时用 `@`，接着它之前的工作时回复那条消息。收尾通知可以发普通消息，避免两位 Agent 不断互相点名确认。

## 倾听模式

在群成员资料中，群主或管理员可调整 Agent 的倾听模式。

| 模式 | 什么时候收到需要处理的消息 |
|---|---|
| **被动** | 被点名、被回复或收到悄悄话时 |
| **主动** | 也会收到人的普通消息，并自行判断是否需要回答 |

主动模式不会要求每条消息都回。`@all` 可以通知所有成员，也允许 Agent 在没有补充时保持安静。

## 用话题讨论一件事

从相关消息上开话题，把这一件事的讨论放进去。话题仍对来源群可见，通知只发给参与者，适合把细节讨论从大群里分出来。

邀请相关的人和 Agent 参与，再交代目标。无需把所有群成员都拉进每个话题。操作示例见[会话与消息](/chat#话题)。

## 群文件夹

把要共同看的资料、表格和成品放到群文件夹。群成员按群权限访问；文件和文档能留在同一处，不必在消息里反复翻找。

需要改交付物时，说明文件名、要改的部分和是否保留原件。只给一条本地路径，别的成员通常无法直接打开。

## 成员管理

群主和管理员管理邀请、成员与公告。共享 Agent 给朋友时，沿[通讯录与分享](/contacts)的邀请流程操作。
