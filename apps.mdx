App 可以提供工作页面，也可以让 Agent 多一种能力，例如搜索资料、打开文档或操作浏览器。左栏「App」里有市场和已安装列表。

## 安装与使用

<Steps>
  <Step title="找到需要的 App">在市场搜索用途或名字，打开详情，查看它能做什么、需要什么权限，以及适用版本。</Step>
  <Step title="确认能力和使用者">带权限的安装会说明能力，按提示指定哪些 Agent 可使用；需要配置或账号连接时，完成对应设置。</Step>
  <Step title="打开或交代工作">有页面的 App 可从左栏或任务「+」打开。工具类 App 可以直接交给允许使用它的 Agent 调用。</Step>
</Steps>

> 用已连接的日历整理本周会议，只列时间冲突，先不修改日程。

「已安装」只说明 App 在这台设备上。执行时还要看启用状态、Agent 范围、账号连接和系统权限。

普通 App 按需从市场安装。群文件夹是唯一预装 App；部分官方 App 属于首启默认组，新用户首次启动时安装，仍可停用和卸载。老用户不追装，卸载后不自动装回。

## 关闭、退出、停用有什么区别

| 操作 | 会发生什么 |
|---|---|
| 关闭页签 | 收起这个页面，App 仍启用，可再打开 |
| 把普通 App 挪到别处 | 同一个实例换位置，已有状态继续保留 |
| 退出 | 收起它的页面并停止后台工作，下次打开重新开始 |
| 停用 | 暂停页面和 Agent 工具，保留文件、数据和已有同意 |
| 卸载 | 移除 App，并清理它保存的数据；操作前看清提示 |

停用或收回权限后，Agent 下一次调用就会按新授权检查。有些 App 为每条任务提供独立页面，例如电脑操作画面，各条任务分别显示。

## 更新与权限

在已安装列表查看更新。默认会更新可兼容的新版；需要时可保留当前版本。新增权限或更换来源的更新，会再次要求确认；已经收回的权限不会因为更新而自动恢复。

App 自己的数据按应用的规则保存；群文件夹中的共享文件不等同于 App 私有数据。卸载前看清要清除的范围。

## 上网和操作电脑

Browser Use 用于网页，Computer Use 用于电脑。安装、启用并完成对应权限后，Agent 才能使用。
