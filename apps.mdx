App 可以是一页工具，也可以提供 Agent 能调用的动作。例如打开文档、搜索资料、操作浏览器。入口在左栏「App」。

## 找到并安装

在 App 市场找需要的应用，查看说明、能力和使用范围，再安装。安装时确认给哪些 Agent 使用；有配置或系统权限要求的，按应用提示完成。

安装后，需要页面的 App 可以从左栏或任务页的「+」打开。停用的 App 不会列在新开页签的菜单里。

<Tip>「页面打开了」和「Agent 有权使用」是两件事。调用失败时，检查启用状态、Agent 使用范围和应用自己的连接设置。</Tip>

## 把 App 放在任务旁边

普通 App 可以移到另一条会话旁或单独打开，原来的状态继续保留。关闭页签只收起页面；需要停止能力时，在「App」页停用或卸载。

有些 App 为每条任务提供独立页面，例如任务自己的电脑操作画面。不同任务各看各的。

## 上网和操作电脑

Browser Use 用于操作网页，Computer Use 用于操作电脑。它们需要安装、启用并获得相应权限，才能让 Agent 使用。
