桌面最左栏底部的齿轮打开统一设置。macOS 也可以按 `⌘ ,`。手机从「我的」进入可用设置。

## 按要做的事找

| 要做什么 | 去哪里 |
|---|---|
| 改称呼、头像、简介，退出登录 | 账户 |
| 看花了多少积分 | 用量 |
| 看会员、厂商账号和可读到的额度 | 订阅 |
| 调整主题和消息通知 | 通用 |
| 调整侧栏显示、启用[资源监视器](/resource-monitor) | 界面 |
| 选择模型菜单里显示哪些模型 | 模型 |
| 添加或管理运行机器 | 设备 |
| 查看版本、提交问题反馈 | 关于 |

与本机工具有关的设置，可能需要先选设备。手机没有对应桌面功能时，也不会显示同样的全部设置项。

个人助理的名字、形象、性格和连接应用，从助理自己的资料和设置进入。

## 更新与版本

**正式版**适合日常稳定使用。**Beta**先提供新功能，文档中的个人助理、跨设备项目和近期 App 操作按当前 Beta 整理，正式版的界面可能不同。

在「关于」查看当前版本。桌面更新下载好后，左栏底部会出现更新入口，点击重启安装；Android 按应用提示下载安装包。更新过程中先保存正在编辑的内容。

正式版只跟随正式版更新，Beta 只跟随 Beta 更新。两者可以同时安装，各自保存应用数据。

当前版本变化见[更新说明](https://gugu.nextmind.space/help/release-notes/macos/)。

## 会员与购买

客户端显示当前权益和用量。开通、续费、加量包和购买记录在[会员面板](https://gugu.nextmind.space/dashboard/)；价格见付款页面。

模型来源和积分有效期见[模型、订阅与积分](/models)。
