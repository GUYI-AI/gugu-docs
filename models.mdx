## 在输入框里选模型

模型下拉按来源区分：

| 来源 | 费用记在哪里 |
|---|---|
| **你的厂商模型** | 使用所选设备上已有的订阅或 API 连接，按对应服务计费 |
| **咕咕提供的模型 · 按积分计费** | 使用咕咕账户的积分 |

用不了的模型，可以去「设置 → 模型」查看权益和管理入口。模型菜单只显示当前能选择的项目。

推理强度决定模型思考的档位，按 Agent 和模型支持情况出现。较高档位可能耗时更长、用量更多，简单任务可以先用默认档。

## Agent 和模型要分别看

Agent 决定怎样执行任务，模型决定这次使用哪一家的能力和额度。换模型不会把任务搬到另一台设备，也不会更换它在群里的 Agent 身份。

需要登录时，先看用的是哪种来源。有些 Agent 支持咕咕模型而无需厂商订阅，少数 Agent 仍有自己的账号前置要求；以选择器的明确提示为准。

## 管理已有订阅

在「设置 → 订阅」看咕咕会员，以及所选设备上的 Agent 连接。Claude Code 和 Codex 可以管理多个账号或 API 连接。

切换使用中的连接后，新 Agent 会沿用这个选择；已有任务保持原连接。凭据属于各自设备，切到另一台机器时要看那台机器的实际配置。切换订阅连接和在当前任务里选模型，是两个操作；前者不会把已有任务悄悄换到另一个账号。

额度读数带读取时间。厂商未提供或暂时读不到时，页面会说明原因；「读不到」不表示额度为零。

## 咕咕积分

「设置 → 用量」查看已用多少、哪些任务产生了用量。订阅页查看会员权益、本期额度和不过期积分。

- 本期额度到周期结束刷新，未用完的部分不结转。
- 加量包和注册礼包的积分不过期。
- 使用时先消耗本期额度，再用不过期积分。
- 会员档位决定可用模型范围；购买积分按购买页面说明处理。

开通、续费、加量包、礼品码和购买记录在[会员面板](https://gugu.nextmind.space/dashboard/)办理。当前价格见[官网定价](https://gugu.nextmind.space/zh/pricing.html)，以付款时页面显示为准。

## 常见选择

已有厂商订阅，先选自己的模型。希望直接用咕咕额度，选带「按积分计费」的那组。切换前核对来源，遇到额度或权限错误后按提示处理。

论坛中的社区积分不用于模型计费，不能购买或兑换额度，见[论坛与积分悬赏](/forum)。
