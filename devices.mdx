任务在选定设备上运行，使用那台机器的文件和程序。手机上发了消息，也不会把服务器里的文件变成手机本地文件。

## 选择运行位置

| 工作 | 设备怎么选 |
|---|---|
| 整理电脑里的资料、修改本地代码 | 文件所在的电脑 |
| 跑服务器上的实验或脚本 | 已连接的 Linux 服务器 |
| 用手机查看进展、补充要求 | 手机负责查看，原设备继续执行 |
| 个人助理持续接待和跟进 | 开通时选择自己的电脑或按权益使用云端 |

同一账号登录桌面版后，这台电脑会出现在设备中。在新建任务时选设备，或从项目卡里选择对应设备上的文件夹。

## 添加另一台机器

打开「设置 → 设备」，选择添加机器。当前提供远程 SSH 和远程隧道，按页面提示填写连接信息、安装并登录。

Linux 服务器运行的是无界面的咕咕 server。能自己登录服务器时，也可以在服务器终端运行官方安装器：

```sh
curl -fsSL https://download.gugu.nextmind.space/releases/server/install.sh | sh
```

安装后按提示登录，使用链接和短码确认设备，再回桌面设备列表查看。已有服务由桌面添加流程管理时，沿原入口连接。

<Note>远程隧道和跨设备项目用法对应当前 Beta。登录确认页会显示要连接的设备，确认后再继续。</Note>

已连接的机器可以在选择器中使用。远程终端、网页和端口能否打开，还取决于当前设备的连接方式。选择器若说明这里只支持「通用」，要用「编程」就按提示在这台电脑上补齐远程 SSH 连接。手机主要用于对话与查看任务。

## 保持工作可用

设备在线只说明连接正常。执行还需要 Agent 可用、账号或模型额度有效，以及所需应用已经授权。

电脑关机、断网或服务停止时，界面会显示离线或连接错误。在原设备恢复服务后，再回原任务继续，先确认上一轮有没有执行到一半。

## 文件不会自动同步

项目可以挂不同设备的文件夹，文件内容仍分别保存在各台机器上。跨设备交付用附件、群文件夹或大家都能访问的仓库。

普通任务运行在所选设备；个人助理的运行位置按[个人助理](/assistant)中的开通与搬家流程管理。

## server 与日常管理

咕咕 server 是远程 Linux 上的无界面运行端，任务使用那台机器的目录和已安装引擎。管理连接、改名或移除机器从「设置 → 设备」进入。桌面窗口关闭与服务器进程停止是不同操作，远程执行是否继续取决于原机器的服务和 Agent 是否仍在运行。

手机查看、回复、审批和附件预览见[手机端](/mobile)。查看本机 CPU 和内存见[资源监视器](/resource-monitor)。
