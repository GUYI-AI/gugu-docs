title: "定时安排"
description: "让 Agent 在指定时间继续工作，查看、修改和停用已经安排的任务。"
---

一次提醒、每天简报或每周检查，都可以直接交代时间、工作内容和结果发到哪里。

> 每周一上午九点，检查项目文件夹里的实验周报，把新增结果总结成五条，发到项目群。使用北京时间。

## 先核对安排

Agent 建好后，检查返回的下一次执行时间、时区和指令。只有看到安排成功及下一次时间，才算已经设好。

一次性任务说清日期；重复任务说清频率；涉及异地时间时明确时区。需要读取文件，就说明设备和文件位置。

## 在哪里查看

| 位置 | 能做什么 |
|---|---|
| 「消息」→「项目」页签 →「已安排」 | 打开「自动化」页，集中查看全部定时工作。可「新建自动化」或「使用模板」；点开一条看「运行记录」和「设置」，可「立即运行」「暂停自动化」或「删除」 |
| 任务输入框上方的定时标签 | 这条任务给自己排的定时，写着几点回来、回来做什么。点开可「改时间」「取消定时」，底部链接跳到「已安排」看全部 |
| 侧栏任务行上的时钟 | 这条任务还有定时，悬停看下一次时间 |
| 个人助理右侧「任务」里的「定时任务」 | 助理安排的定时工作 |
| Agent 设置里的「定时任务」页 | 这个 Agent 的定时任务，可「创建任务」「暂停」或「删除任务」 |

「改时间」提供「+30 分钟」「+1 小时」「明早 9 点」等快捷选项，也能填重复规则。改完确认新时间已经生效。

要修改内容，直接对 Agent 说明是哪条安排，以及改成什么。不再需要时取消或删除。

### 错过和没送到

到点时电脑没开，或上一次还没跑完，标签会带上警示图标，写明这一条「错过了」及原因。点开选「现在补一次」立刻补跑，或选「不用了」。

到点没送出去，例如当时咕咕重启了，标签会写明这一条「没送到」。点开选「重试」，或选「不用了」。

## 执行时需要什么

定时工作依赖对应的运行设备、模型额度和应用授权。自己的电脑离线时，它无法在那台电脑上读文件或执行程序。

「已安排」只表示有一条未来工作。执行后要看当次消息和实际结果；失败时按设备、授权或额度提示处理。到点送达时，任务里会出现一条带「已安排」和「到点」字样的记录。
