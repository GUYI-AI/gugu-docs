这一页做一个能保存草稿的便签。完成后你会得到一个可安装的 App 文件夹，并在任务里打开它、保存文字、重开后看到文字还在。整章路线见[贡献 App](/apps/contribute)。

## 准备

- 一台装有咕咕桌面版的电脑和一个文本编辑器。这个示例没有构建步骤，不需要 Node。
- 之后要上架市场时，再准备 Git、Node.js 24 或更高版本，以及一个公开的 GitHub 仓库。

## 写三份文件

新建 `notes-starter` 文件夹，放入下面三份文件。同样的文件也在[文档仓库的起步示例](https://github.com/GUYI-AI/gugu-docs/tree/main/samples/app-starter)里。

```text
notes-starter/
  manifest.json
  main.html
  main.js
```

`manifest.json` 声明身份、适用设备、接口版本和一个页面。它不申请任何权限。

```json
{
  "id": "notes-starter",
  "name": "便签起步",
  "description": "在 App 页面里保存一份本机草稿。",
  "version": "1.0.0",
  "apiVersion": 12,
  "platforms": ["desktop"],
  "engines": { "gugu": ">=0.2.57" },
  "entry": "main.html",
  "contributes": {
    "tabs": [{ "name": "notes", "title": "便签", "entry": "main.html" }]
  }
}
```

- `platforms` 说明人用的界面在哪类设备上可用。安装和上架都要求它，且要求 `apiVersion` 至少为 12。
- `apiVersion` 写你用到的接口所需的最低版本。客户端拒装高于自己的版本。这个起步包只用到 `getContext`，写 12 就能装进正式版和 Beta。
- `engines.gugu` 只接受 `>=x.y.z` 或 `^x.y.z`，表示能运行的最低咕咕版本。本机安装可以不写，上架必须写。

`main.html` 只写结构。页面已经带有咕咕的样式和明暗主题。

```html
<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>便签起步</title></head>
<body>
  <main>
    <h1>便签</h1>
    <label for="draft">本机草稿</label>
    <textarea id="draft" rows="8"></textarea>
    <button id="save" type="button">保存</button>
    <p id="status" role="status"></p>
  </main>
  <script src="main.js"></script>
</body>
</html>
```

脚本必须放在单独的 `.js` 文件里，用 `<script src>` 引入。写在 HTML 里的内联脚本会被拦下，不会运行。

`main.js` 读写草稿，并把失败原因显示出来。

```js
const draft = document.getElementById('draft');
const statusLine = document.getElementById('status');
const saveButton = document.getElementById('save');

try {
  draft.value = localStorage.getItem('draft') ?? '';
} catch (error) {
  statusLine.textContent = `读取失败：${error.message}`;
}

saveButton.addEventListener('click', () => {
  try {
    localStorage.setItem('draft', draft.value);
    statusLine.textContent = '已保存到这个 App 的本机存储';
  } catch (error) {
    statusLine.textContent = `保存失败：${error.message}`;
  }
});

window.gugu.getContext().then((context) => {
  document.documentElement.lang = context.locale || 'zh-CN';
}).catch((error) => {
  statusLine.textContent = `读取 App 环境失败：${error.message}`;
});
```

不要在脚本顶层写 `const gugu = window.gugu`。它会和平台的全局名称冲突，整个脚本都不会运行。

## 装进咕咕

<Steps>
  <Step title="从文件夹安装">
    打开左栏「App」，点「装本地文件夹」，选择 `notes-starter`。这个示例不申请权限，会直接装上。
  </Step>
  <Step title="放进任务">
    装好后出现「已安装 便签起步」提示，并说明在会话的「+」里放入「便签」。打开一个任务，点「+」，选「便签」。
  </Step>
  <Step title="保存一条草稿">
    输入「明天整理文献」，点「保存」，页面下方出现「已保存到这个 App 的本机存储」。
  </Step>
</Steps>

安装失败时，咕咕会显示「安装失败」和具体原因。常见原因是 `apiVersion` 高于这台客户端支持的版本，提示会写明它最高支持多少。更新客户端，或把 `apiVersion` 改成你所用接口需要的最低版本。用到 `platforms` 时不能低于 12。

## 改代码后重装

1. 改 `main.html` 里的标题，例如把「便签」改成「我的便签」。
2. 回到 App 页，再点「装本地文件夹」，选择同一个文件夹。同一个 id 会被新文件替换；没有新增权限时直接装上。
3. 重新打开页面，确认标题已经变化，之前保存的草稿仍在。

从文件夹装的 App 只装在这台电脑上。要装到其他电脑，发成卡片或从市场安装。

## 检查点

- 页面能在任务中打开，保存后显示结果。
- 关掉页面再打开，草稿仍在。草稿只在这台电脑上，不会同步给其他设备或群成员。
- 切换明暗主题、把页面拉窄，标签、输入框和按钮都能正常使用。
