# 2026-10 文档维护范围

当前文档从 2026-10-20 的 main `6d034d8` 继续维护。现有入门、任务、项目、App、模型及远程说明保留，本轮补足贡献入口、论坛、资源监视器与手机说明。

| 用户问题 | 维护前 | 当前事实与维护方向 |
| --- | --- | --- |
| 任务如何分屏 | 已说明单任务双页与多任务拖动，称呼混有会话 | 统一任务名称，区分任务内双页与多个独立工作区 |
| 引擎、Agent、模型如何选 | 执行工具和身份均叫 Agent | 用引擎指执行工具；模型来源与 Agent 身份分别说明 |
| 普通 App 是否自带 | 市场与更新已有，首启组边界缺失 | 唯一预装为群文件夹；firstRun 只对官方索引仓自己的 App 生效 |
| 如何贡献 App | PR #2 的 API 1 两页未合 | 按当前 API 9 契约组织起步、manifest、API、调试、提交和维护 |
| 如何参与悬赏 | 缺页 | 普通市场 App、社区积分与额度区别、确认和结算 |
| 怎样看 CPU/内存 | 缺页 | 资源监视器开关、命令面板、项目/任务分组和复制报告 |
| 手机能做什么 | 设备页中零散介绍 | 手机看管在线机器、审批/提问和文件预览，手机能力单独授权 |
| server 与桌面如何配合 | 已有安装器与远程连接说明 | 保留安装器，补连接断开与远程执行的边界 |

[PR #2](https://github.com/shuxueshuxue/gugu-docs/pull/2)（`0a99bf9`）保留的思路是完整最小示例、沙箱/联网、逐项授权及错误处理；其 API 1、taskId、切页重载和不支持 Agent 控制等旧断言不再作为接口依据。新接口页指向产品内指南和真实 schema，避免再维护一份自称完整但过期的清单。
