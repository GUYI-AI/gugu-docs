## 开一个话题

1. 找到要继续讨论的消息，打开消息菜单，选「开话题」。
2. 话题名默认取自原消息开头。需要时在「话题成员」列表顶部改名。
3. 在话题里 `@` 需要参与的人或 Agent，再说明要做什么。

桌面上，话题在来源聊天旁边分栏展开。「收起分栏」只收起这一栏，话题不会关闭。手机上，话题占满整页。

原消息下方会出现话题入口，写着条数和参与人数，点它即可进入。

## 谁看得见，谁收到通知

| 问题 | 规则 |
|---|---|
| 群里其他人看得见吗 | 能看见，也能点进来读 |
| 哪些人收到后续通知 | 在里面说过话或被点名加入的参与者 |
| 还不是参与者怎么办 | 在话题里说一句，就成为参与者 |
| 新开话题会换 Agent 或工作目录吗 | 不会，仍由同一位 Agent 在原运行位置工作 |

## 找到所有话题

在群聊页头打开「更多操作」，进入「话题」。这里列出本群全部话题，带最近时间、预览和未读数。已置顶的排在最前。

## 置顶到群聊页签

在「话题」列表里，点话题右侧的图钉「将“话题名”置顶到主群」。

置顶后，群聊页头下方出现一排页签。第一枚是「群聊」，后面每个置顶话题一枚。点一枚就切到那个话题，再点「群聊」回到主群。桌面和手机用同一排页签。

置顶只影响你自己的页签，不改变别人看到的样子。取消时点同一个图钉「取消置顶“话题名”」。

手机上的私聊里，所有话题都直接排成页签，无需置顶。

## 项目里的任务

在项目群里交给 Agent 的任务，会以任务卡开出自己的话题。把它置顶后，页签上会标出这件任务是在进行还是等你处理。

## Agent 太多时

话题沿用来源群的 Agent 数量上限，超过后全员转为被动，只有 `@` 点名才叫得醒。群的上限在「群管理 → Agent 协作」设置，见[群与协作](/groups#倾听模式)。

私聊里可以为每个话题单独设：打开「更多操作 → 会话信息」，在「话题阈值」里选话题，再填数字。留空则跟随来源对话。
