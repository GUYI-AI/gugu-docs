# 演示媒体

## 真实界面步骤图解

`quickstart-native.mp4` 来自 2026-10-21 的官方 Beta `0.2.57-beta.125.1` 独立副本。测试账号和两项数据目录隔离，连接 shared-test；材料为虚构会议记录。新建、粘贴、生成纪要、原会话修改同一文件均实际完成。

短片以三张原始窗口截图串联，停留时间编排为 6 / 8 / 10 秒；不是连续录屏，也不表达模型耗时。源截图在 `images/walkthrough/`：01、02、04。仅在视频上方增加字幕区，界面内容未重绘。1280 × 996，H.264 / yuv420p / faststart，无音轨，配 JPG 封面和 VTT 字幕源。

验收遇到过服务不可用、测试账号无积分，以及另一个任务写出文件后模型容量不足；未抹成“全程一次成功”。后两项对应的恢复方法已写入教程和帮助。测试准备中的接口登录与积分夹具不属于普通用户教程。

## 官网界面动画

来源：`nmhjklnm/gugu-website`，提交 `0f17fc394cde1b557deaad4379ffbb82f87ec1f6`，`zh/ui/demo.js`、`zh/ui/demo.css` 及其素材。原动画说明以 v0.2.57 开发界面为参照，产品参照提交 `0367a7f7cc`。

录制于 2026-10-21。1280 × 864（顶部 64 像素字幕区与 800 像素界面），H.264 / yuv420p，MP4 faststart，无音轨。每段配同名 JPG 封面和内置中文字幕及同内容 VTT 源文件。页面使用原生播放、暂停、拖动、全屏控制，不自动播放，不预加载整个视频。

| 文件 | 场景 |
|---|---|
| `group.mp4` | 建群与点名分工 |
| `topic.mp4` | 从消息展开话题 |
| `apps.mp4` | 制作并使用标题投票 App |
| `split.mp4` | 在任务中并排查看结果 |
| `buform.mp4` | 浏览器表单填写 |

这些是界面场景动画，使用虚构的人物与示例结果，不属于真实任务录屏或产品验收证据。教程正文的功能另按产品 behavior、界面代码核对。未来界面变化时需同步重录，不应用媒体中的演示耗时推断真实任务耗时。

Mintlify 当前会过滤 HTML track 元素，字幕随画面录制，保证内嵌和全屏均可读。VTT 保留为字幕源，正文步骤提供独立文字说明。
字幕置于画面顶部，避免原生播放控制条覆盖文字。
