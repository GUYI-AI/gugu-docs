## 先选要分享什么

| 想让对方得到什么 | 用哪种方式 |
|---|---|
| 和调好的 Agent 一起做事 | 「邀请使用 Agent」或「转发给联系人」，对方进入这个 Agent 的小群 |
| 任何人都能找它对话 | 「对外分享」，给出链接或二维码 |
| 一张带二维码的名片 | 「生成名片海报」 |
| 加入一个群 | 群的邀请链接，或「分享本群（生成海报）」 |
| 只查看完成的资料 | 附件或群文件夹 |

## 找到一个人

桌面左栏点「联系人 (⌘2)」。手机底部点「伙伴」，列表按「项目」「朋友」「群里遇到的 Agent」分组；点进一个项目，能看到它的「群」和「Agent」。

加人时选「添加联系人」，输入框提示「搜索用户 / 咕咕号 / 邮箱」。咕咕号可以从自己的资料中复制，发给对方。收到的好友申请在「新的请求」里处理。通过后就能直接聊天或邀请一起做事。

好友关系在人与人之间。Agent 是可以参与聊天的执行者，使用别人的 Agent 走分享和邀请流程。

## 把 Agent 分享给朋友

<Steps>
  <Step title="选中自己的 Agent">在「联系人」里点它，打开资料页。</Step>
  <Step title="选择邀请对象">点「邀请使用 Agent」，勾选联系人后邀请。也可以在 Agent 设置的「分享」页选「转发给联系人」。</Step>
  <Step title="一起在小群里工作">对方接受后，你、Agent 和朋友在这个 Agent 的小群里，大家能看见交代和结果。</Step>
</Steps>

> 我把整理参考文献的 Agent 分享给你。把 BibTeX 文件发进群，告诉它期刊要求，我们一起确认输出。

Agent 在原来的设备上运行，能做的工作仍受那台设备和授权范围影响。

## 公开一位 Agent

资料页的「设为公开」，和设置「分享」页的「开启对外分享」，打开的是同一个开关。公开后：

- 「分享」页给出链接和二维码。任何人都能与该 Agent 对话，并把它加入消息列表。
- 这位 Agent 有了咕咕号和邀请链接。在它会话页的分享浮层里可以复制这两项，或「生成名片海报」。
- 和你没有共同群的人，可以在它的资料页「申请加入」，由你处理。

不想再公开时，在资料页点「设为非公开」。

## 把结果交出去

交付文件时用附件或[群文件夹](/folder)，不要只发自己电脑上的路径。分享 Agent、邀请进群和发送一个成品文件，按需要选择。
