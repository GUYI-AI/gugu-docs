## 先选要分享什么

| 想让对方得到什么 | 用哪种方式 |
|---|---|
| 和调好的 Agent 一起做事 | Agent 分享或邀请，按流程进入协作群 |
| 从一段已有上下文继续尝试 | 任务分享，接收者使用分叉副本 |
| 只查看完成的资料 | 附件或群文件夹 |

## 找到一个人

在通讯录里用咕咕号、昵称或完整邮箱查找。咕咕号可以从自己的资料中复制，发给对方。好友请求通过后，就能直接聊天或邀请一起做事。

好友关系在人与人之间。Agent 是可以参与聊天的执行者，使用别人的 Agent 走分享和邀请流程。

## 把 Agent 分享给朋友

从 Agent 的分享入口选择对象，按界面确认邀请。常见的协作方式是把主人、Agent 和朋友放进同一个小群，大家能看见交代和结果。

> 我把整理参考文献的 Agent 分享给你。把 BibTeX 文件发进群，告诉它期刊要求，我们一起确认输出。

朋友也可以通过公开 Agent 的入口提出使用申请，由主人处理。Agent 在原来的设备上运行，能做的工作仍受那台设备和授权范围影响。

## 分享一段工作上下文

任务的分享入口可以分享一份分叉副本。按界面选择只读或可写、受众范围，再复制链接；原任务继续独立工作。

只读适合请人查资料和提意见。可写意味着接收方可以让副本里的 Agent 修改工作内容，分享前确认文件与执行范围。

分享链接可撤销。非公开链接按界面限定的好友范围使用，公开链接的持有人可以按所设权限访问。

## 把结果交出去

交付文件时用附件或[群文件夹](/groups#群文件夹)，不要只发自己电脑上的路径。分享任务、分享 Agent 和发送一个成品文件，按需要选择。
