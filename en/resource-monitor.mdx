---
title: "Resource monitor"
description: "See CPU and memory use by gugu and running tasks, and find the work that needs attention."
---

When your computer slows down, check which tasks and programs are using resources first. **Resource monitor** shows readings for this computer. Model credits and provider quotas are in [Usage and models](/en/models).

## Open it

1. On desktop, open **Settings → Interface** and turn on **Resource monitor**.
2. Open the command palette, search for **Resource monitor**, and open it. You can view or change the command palette shortcut under keyboard shortcuts in settings.
3. Wait for readings to load, then check CPU and Mem at the top, and the app processes, projects, and task groups below.

## Read the numbers

CPU is processor use at the time of sampling. Mem is memory use. Both change with what programs are currently doing. Right after opening, before there is a baseline, some values are not shown yet.

The list groups running items by project and task, and also shows gugu's own processes. Find the work first, then judge whether it is still running and whether it should continue. High resource use does not mean a task failed, and low use does not mean it was delivered.

Remote tasks run on another machine. Do not read this computer's numbers as the server's usage. To check the original machine, use the tools on that machine.

## Manage running processes and report problems

You can go back to the task to check progress first. To stop a running item in the list, click **Stop** and confirm again. Files already written and external actions already completed are not undone.

Resource monitor can copy a report. When reporting a problem, attach the report, your gugu version, and the steps to reproduce. Before sharing, check whether project names, paths, and similar details are fine to make public.

If the interface is still loading or the report is missing a reading, refresh or reopen it later. No reading does not mean zero usage.
