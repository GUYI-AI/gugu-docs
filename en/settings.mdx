On desktop, the gear at the bottom of the far-left column opens Settings. On macOS you can also press `⌘ ,`. On the phone, open the available settings from **Me**.

## Find by task

| What to do | Where |
|---|---|
| Change display name, avatar, bio, or sign out | **Account** |
| See how many credits you have spent | **Usage** |
| See membership, provider accounts, and readable quotas | **Subscriptions** |
| Adjust theme and message notifications | **General** |
| Adjust sidebar display, enable the [Resource monitor](/en/resource-monitor) | **Interface** |
| Choose which models appear in the model menu | **Models** |
| Add or manage the machines that run Agents | **Devices** |
| Check the version, send feedback | **About** |

Settings related to tools on a machine may require choosing a device first. When the phone lacks a desktop feature, it does not show the same full set of settings.

The personal assistant's name, look, personality, and connected apps are set from the assistant's own profile and settings.

## Updates and versions

The **stable release** suits stable everyday use. **Beta** gets new features first. The personal assistant, cross-device projects, and recent App actions in these docs follow the current Beta. The stable release's interface may differ.

Check the current version in **About**. When a desktop update has downloaded, an update entry appears at the bottom of the left column. Click it to restart and install. On Android, download the installer as the app prompts. Save anything you are editing before updating.

The stable release only updates to stable releases, and Beta only to Beta. You can install both at once. Each keeps its own app data.

For recent changes, see the [release notes](https://gugu.nextmind.space/help/release-notes/macos/).

## Membership and purchases

The client shows your current entitlements and usage. Sign up, renew, buy top-up packs, and see purchase history in the [membership dashboard](https://gugu.nextmind.space/dashboard/). Prices are shown on the checkout page.

For model sources and credit validity, see [Models, subscriptions, and credits](/en/models).
