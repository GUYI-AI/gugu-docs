## Divide work between two Agents

<video controls playsInline preload="none" poster="/videos/group.jpg" aria-label="Demo: creating a group and dividing work" style={{width: '100%', borderRadius: '12px'}}>
  <source src="/videos/group.mp4" type="video/mp4" />
</video>

Create a group, pick members, and mention each one and state the result you want from each. Whoever finishes first posts the output to the group, and the next one continues from it.

> @Research Assistant organize the literature table by research question. @Writing Assistant once the table is confirmed, write a one-page summary.

[Groups and collaboration](/en/groups)

## Open a topic from a message

<video controls playsInline preload="none" poster="/videos/topic.jpg" aria-label="Demo: message topics" style={{width: '100%', borderRadius: '12px'}}>
  <source src="/videos/topic.mp4" type="video/mp4" />
</video>

Find the message that needs discussion, open a topic, and bring in the relevant members. All the back-and-forth on one issue stays in one place.

> Revise this version of the summary in this topic first. Once it's confirmed, post the final draft back to the project group.

[Topics](/en/topics)

## Build a small work tool

<video controls playsInline preload="none" poster="/videos/apps.jpg" aria-label="Demo: building an App" style={{width: '100%', borderRadius: '12px'}}>

Describe the purpose and the minimum actions. When the Agent has the App ready, confirm the installation prompt, then open it and try it.

> Make a poll to choose the group meeting title. List three candidate titles, let each person pick one, and show the current vote count.

## Revise while looking at the result

<video controls playsInline preload="none" poster="/videos/split.jpg" aria-label="Demo: side-by-side viewing" style={{width: '100%', borderRadius: '12px'}}>
  <source src="/videos/split.mp4" type="video/mp4" />
</video>

Open a file or page from the task, next to the chat. Ask for the next revision while looking at the result.

> Keep the current structure, cut the second paragraph to three sentences, and open the revised file beside the chat when you're done.

[Task workspace](/en/tasks)

## Fill in a web form

<video controls playsInline preload="none" poster="/videos/buform.jpg" aria-label="Demo: web form" style={{width: '100%', borderRadius: '12px'}}>

Once Browser Use is enabled and has the needed permissions, let the Agent operate web pages. The clip fills in and submits a trial form with the information given. For real tasks, say how far it is allowed to go.

> Fill in the registration form using this document. Ask me about any missing information first, and stop before submitting.
