title: "Schedules"
description: "Have an Agent continue work at a set time, and view, change or turn off what is already scheduled."
---

A one-time reminder, a daily briefing or a weekly check: just state the time, the work, and where the result should go.

> Every Monday at 9 a.m., check the weekly experiment reports in the project folder, summarize new results in five points, and post them to the project group. Use Beijing time.

## Check the schedule first

After the Agent sets it up, check the returned next run time, time zone and instruction. It is set up only once you see that scheduling succeeded and the next run time.

For a one-time task, give the date. For a recurring task, give the frequency. When other locations' times are involved, state the time zone. If it needs to read files, name the device and file location.

## Where to view it

| Where | What you can do |
|---|---|
| **Messages** → **Projects** tab → **Scheduled** | Opens the **Automations** page with all scheduled work. Use **New Automation** or **Use a template**. Open one to see **Runs** and **Settings**, and to **Run now**, **Pause automation** or **Delete** |
| The schedule label above a task's input box | What this task scheduled for itself: when it comes back and what it will do. Open it to **Change time** or **Cancel schedule**; the **See all in Scheduled** link at the bottom jumps to **Scheduled** |
| The clock on a task row in the sidebar | This task still has a schedule. Hover to see the next time |
| **Scheduled** under **Tasks** on the personal assistant's right-hand panel | Scheduled work the assistant set up |
| The **Scheduled tasks** page in an Agent's settings | That Agent's scheduled tasks. Use **Create task**, **Pause** or **Delete task** |

**Change time** offers shortcuts such as **+30 min**, **+1 hour** and **Tomorrow 9:00**, and also accepts a repeat rule. Afterwards, confirm the new time has taken effect.

To change what it does, tell the Agent which schedule it is and what to change it to. When you no longer need it, cancel or delete it.

### Missed or not delivered

If the computer was off at the due time, or the previous run was still going, the label shows **“Title” was missed** with the reason. Open it and choose **Run it now** to catch up, or **Never mind**.

If it was due but not delivered, for example because gugu restarted, the label shows **“Title” was not delivered**. Open it and choose **Retry**, or **Never mind**.

## What it needs to run

Scheduled work depends on the device it runs on, model quota and app authorizations. While your own computer is offline, it cannot read files or run programs on that computer.

**Scheduled** only means the task is set to run in the future. After it runs, check that run's message and actual result. If it fails, follow the prompts about the device, authorization or quota. When a schedule is delivered, the task shows **scheduled “Title”, due now**.
