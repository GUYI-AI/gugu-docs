title: "Schedules"
description: "Have an Agent continue work at a set time, and view, change or turn off what is already scheduled."
---

A one-time reminder, a daily briefing or a weekly check: just state the time, the work, and where the result should go.

> Every Monday at 9 a.m., check the weekly experiment reports in the project folder, summarize new results in five points, and post them to the project group. Use Beijing time.

## Check the schedule first

After the Agent sets it up, check the returned next run time, time zone and instruction. It is set up only once you see that scheduling succeeded and the next run time.

For a one-time task, give the date. For a recurring task, give the frequency. When other locations' times are involved, state the time zone. If it needs to read files, name the device and file location.

## Where to view it

**Scheduled** in the task workspace sidebar collects scheduled work in one place. Work the personal assistant scheduled can also be viewed under **Tasks → Scheduled tasks** on the assistant's right-hand panel.

To change the time or content, say which schedule it is and what to change it to. Confirm the new time has taken effect. When you no longer need it, turn it off or delete it.

## What it needs to run

Scheduled work depends on the device it runs on, model quota and app authorizations. While your own computer is offline, it cannot read files or run programs on that computer.

**Scheduled** only means the task is set to run in the future. After it runs, check that run's message and actual result. If it fails, follow the prompts about the device, authorization or quota.
