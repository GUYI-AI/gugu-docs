This page builds a notes App that saves a draft. At the end you have an installable App folder, open it in a task, save some text and see it again after reopening. The whole chapter's roadmap is in [Contribute an App](/en/apps/contribute).

## Prerequisites

- A computer with gugu desktop and a text editor. This example has no build step and does not need Node.
- When you later publish to the market, you also need Git, Node.js 24 or later, and a public GitHub repository.

## Write three files

Create a `notes-starter` folder and add the three files below. The same files are in the [starter sample in the docs repository](https://github.com/GUYI-AI/gugu-docs/tree/main/samples/app-starter). The sample keeps its Chinese interface strings: the tab title 便签 means "Notes", and 保存 is "Save". Replace them with your own wording.

```text
notes-starter/
  manifest.json
  main.html
  main.js
```

`manifest.json` declares the identity, supported devices, API version and one page. It requests no permissions.

```json
{
  "id": "notes-starter",
  "name": "便签起步",
  "description": "在 App 页面里保存一份本机草稿。",
  "version": "1.0.0",
  "apiVersion": 12,
  "platforms": ["desktop"],
  "engines": { "gugu": ">=0.2.57" },
  "entry": "main.html",
  "contributes": {
    "tabs": [{ "name": "notes", "title": "便签", "entry": "main.html" }]
  }
}
```

- `platforms` says which kinds of device the human-facing interface supports. Installing and publishing both require it, with `apiVersion` 12 or higher.
- Set `apiVersion` to the lowest version the APIs you use need. A client refuses Apps above its own version. This starter only calls `getContext`, so 12 installs on both the stable and Beta clients.
- `engines.gugu` accepts only `>=x.y.z` or `^x.y.z`: the oldest gugu version the App runs on. A local install can omit it. Publishing requires it.

`main.html` holds only structure. The page already has gugu's styles and light and dark themes.

```html
<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>便签起步</title></head>
<body>
  <main>
    <h1>便签</h1>
    <label for="draft">本机草稿</label>
    <textarea id="draft" rows="8"></textarea>
    <button id="save" type="button">保存</button>
    <p id="status" role="status"></p>
  </main>
  <script src="main.js"></script>
</body>
</html>
```

Scripts must be separate `.js` files loaded with `<script src>`. An inline script inside the HTML is blocked and does not run.

`main.js` reads and saves the draft and shows any failure.

```js
const draft = document.getElementById('draft');
const statusLine = document.getElementById('status');
const saveButton = document.getElementById('save');

try {
  draft.value = localStorage.getItem('draft') ?? '';
} catch (error) {
  statusLine.textContent = `读取失败：${error.message}`;
}

saveButton.addEventListener('click', () => {
  try {
    localStorage.setItem('draft', draft.value);
    statusLine.textContent = '已保存到这个 App 的本机存储';
  } catch (error) {
    statusLine.textContent = `保存失败：${error.message}`;
  }
});

window.gugu.getContext().then((context) => {
  document.documentElement.lang = context.locale || 'zh-CN';
}).catch((error) => {
  statusLine.textContent = `读取 App 环境失败：${error.message}`;
});
```

Do not write `const gugu = window.gugu` at the top level of a script. It clashes with the platform's global name and the whole script stops running.

## Install it in gugu

<Steps>
  <Step title="Install from the folder">
    Open **Apps** in the left column, click **Install from folder** and choose `notes-starter`. This example requests no permissions, so it installs at once.
  </Step>
  <Step title="Put it in a task">
    A notice says the App is installed and that you can put "便签" into a task from its **+**. Open a task, click **+** and choose **便签**.
  </Step>
  <Step title="Save a draft">
    Type "Organize the literature tomorrow" and click **保存** (Save). The line under the button says the draft was saved to this App's local storage.
  </Step>
</Steps>

If installation fails, gugu shows **Install failed** with the reason. A common cause is an `apiVersion` higher than this client supports; the message gives the highest it supports. Update the client, or lower `apiVersion` to what the APIs you use need. With `platforms` it cannot go below 12.

## Reinstall after a change

1. Change the heading in `main.html`, for example from 便签 to 我的便签.
2. Back on the Apps page, click **Install from folder** again and choose the same folder. The new files replace the App with the same id. With no new permissions it installs at once.
3. Reopen the page. Check that the heading changed and the saved draft is still there.

An App installed from a folder is on this computer only. To put it on another computer, send it as a card or install it from the market.

## Checkpoint

- The page opens in a task and shows a result after saving.
- Close and reopen the page: the draft is still there. It stays on this computer and does not sync to other devices or group members.
- Switch between light and dark themes and narrow the page. Labels, the text box and the button all still work.
