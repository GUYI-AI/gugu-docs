The personal assistant handles everyday questions, memory and follow-up on work. Work that needs hands-on or ongoing execution can go to a task Agent.

<Note>This page describes the current Beta. The entry point is the assistant avatar in the far-left column on desktop. During setup, you choose where it runs based on your account entitlements and devices.</Note>

## Setup and first instructions

Click the assistant avatar and choose **Set up my Gugu**. Give it a name, then choose whether it lives on this computer or in the cloud. If the cloud is not open yet, the page says so. Whether this computer can host it also follows the current prompt. You can add connected apps later. Your name and identity come from your account profile, so you do not need to introduce yourself again.

> I'm preparing for a group meeting. First learn my research area. From now on, keep outlines within one page and cite sources for paper conclusions. Keep my passing thoughts separate from the original text.

Ask it to remember long-term agreements. For requests that apply only this time, say so. The **Memory** page shows existing entries; change or delete them in the chat.

## Using the right-hand panel

| Place | What it is for |
|---|---|
| Today | View briefings and diary entries already generated, or ask for the latest briefing |
| **Tasks** | See work the assistant actually assigned and its scheduled items; open one to chat with the executor directly |
| **Memory** | View what it knows long-term, agreements, and related project material |
| **Profile** | Change its name, **Look** and **Personality**; view available capabilities, devices and app connections |

On desktop, chat with the assistant on the left and view tasks on the right. A task chat opens on the right; going back returns to the task list. The personal assistant chat stays where it was.

On the phone, open the assistant and switch between chat, Today, **Tasks**, **Memory** and **Profile**. Opening a task keeps you inside the assistant's content area.

## When to hand work to a task Agent

You can say plainly: "Please hand this to a task Agent." The assistant arranges the work using existing executors, material and devices. One-off work does not need a project first.

When an executor is missing key information, the assistant can come back with questions for you to confirm. Options must be submitted explicitly. Closing the question or answering later does not count as a decision.

To try the full loop from handing over work to checking it, see [Have the assistant assign and follow up on a piece of work](/en/guides/assistant-follow-up).

## Where it runs, moving, and turning it off

An assistant on this computer can use your own subscriptions on this computer or models provided by Gugu. A cloud assistant uses Gugu credits and requires cloud service to be open in your environment. While the computer sleeps or is shut down, a local assistant cannot keep working. Messages and briefings that came due are handled after the computer wakes.

To move it, follow the steps on the page. It stays the same assistant, with its identity, memory and personality. Moving to the cloud does not carry over the vendor subscription logins on this computer.

Turning off the assistant deletes the memory, files and scheduled tasks listed in the confirmation dialog. This cannot be undone. You choose whether the tasks it created are deleted too; by default they are kept. To just hide the panel, use the collapse control on the panel.
