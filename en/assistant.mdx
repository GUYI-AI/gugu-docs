The personal assistant handles everyday questions, memory and follow-up on work. For work that involves files, tools, or ongoing follow-up, ask it to assign a task Agent.

<Note>This page describes the current Beta. On desktop, the entry point is the Gugu avatar at the top of the left rail. On the phone, it is the first row in **Messages**. During setup, you choose where it runs based on your account entitlements and devices.</Note>

## Setup and first instructions

Click the assistant avatar and choose **Set up my Gugu**. Give it a name, then choose whether it lives on this computer or in the cloud. The setup page tells you whether cloud hosting or hosting on this computer is available. You can add connected apps later. Your name and identity come from your account profile, so you do not need to introduce yourself again.

> I'm preparing for a group meeting. First, ask me about my research area. From now on, keep outlines within one page and cite sources for paper conclusions. Keep my own ideas separate from the source material.

Ask it to remember long-term agreements. For requests that apply only this time, say so. The **Memory** page shows existing entries; change or delete them in the chat.

## Using the right-hand panel

| Place | What it is for |
|---|---|
| **Activity** | View briefings and diary entries already generated, or ask for the latest briefing |
| **Tasks** | See work the assistant actually assigned and its **Scheduled** items; open one to chat with the task Agent directly |
| **Memory** | View what it knows long-term, agreements, and related project material |
| **Profile** | Change its name, **Look** and **Personality**; view available capabilities, devices, and app connections |

On desktop, chat with the assistant on the left and view tasks on the right. A task chat opens on the right; going back returns to the task list. The personal assistant chat stays where it was.

On the phone, open **Messages** and tap the assistant in the first row. It opens as its own full page. The header switches between **Chat**, **Activity**, **Tasks**, **Memory** and **Profile**. Opening a task keeps you on the assistant's page, and going back returns to the task list.

## When to hand work to a task Agent

You can say plainly: "Please hand this to a task Agent." The assistant arranges the work using available Agents, material, and devices. One-off work does not need a project first.

When a task Agent is missing key information, the assistant can come back with questions for you to answer. Options must be submitted explicitly. Closing the question or answering later does not count as a decision.

To try the full loop from handing over work to checking it, see [Have the assistant assign and follow up on a piece of work](/en/guides/assistant-follow-up).

## Where it runs, moving, and turning it off

An assistant on this computer can use your own subscriptions on this computer or models provided by gugu. A cloud assistant uses gugu credits and requires cloud hosting to be available in your environment. While the computer sleeps or is shut down, a local assistant cannot keep working. Pending messages and scheduled briefings are handled after the computer wakes.

To move it, follow the steps on the page. It stays the same assistant, with its identity, memory and personality. Moving to the cloud does not carry over the vendor subscription logins on this computer.

Turning off the assistant deletes the memory, files and scheduled tasks listed in the confirmation dialog. This cannot be undone. You choose whether the tasks it created are deleted too; by default they are kept. To just hide the panel, use the collapse control on the panel.
