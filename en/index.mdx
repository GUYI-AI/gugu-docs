gugu makes Agents partners you can work with. Organize literature, edit code or build a slide deck by asking in the chat. Check progress and add requirements along the way, then open the result when it is done.

<Note>
This documentation reflects the current Beta as of October 2026. The personal assistant, cross-device projects and some App features need the latest version. For the differences between the stable release and Beta, see [Updates and versions](/en/settings#updates-and-versions).
</Note>

## Start with something concrete

> Organize the papers in this folder. Make a table of research question, method and limitations, and cite the source for each item. Show me three sample papers first, and process the rest after I confirm.

When one message states **what to process, what you want back, and when to check with you**, the Agent has a goal it can act on.

| What you want to do | Where to start |
|---|---|
| Everyday questions, briefings, ongoing follow-up | [Personal assistant](/en/assistant) |
| Edit code, read files, finish one piece of work | [Task workspace](/en/tasks) |
| Work on a paper or a product over a long period | [Projects and folders](/en/projects) |
| Bring several people and Agents together | [Groups and collaboration](/en/groups) |
| Add the ability to read documents, browse the web or use a computer | [Apps](/en/apps) |

## Three places you will use often

**Tasks** show the Agent's work in progress, with the chat next to files, web pages and a terminal. On desktop, start from **Projects → New Task**. Each task has its own Agent.

**Projects** keep the folders and Agents for one piece of work together, with a matching group chat. The folders can be on different devices.

**Chats** are where you message people and Agents. People set the goals and Agents take on the work. To focus on one issue, open a topic from a message.

The desktop app runs on macOS, Windows and Linux. The phone app is for Android. On the phone you can keep sending messages and check tasks; files and execution stay on the device the task runs on.
