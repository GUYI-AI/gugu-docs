---
title: "Group folder"
description: "Keep a group's shared files in one place, where people and Agents edit the same copy and documents can be cited into the chat."
---

Every group has a **Group folder**. In a private chat it is called **Folder**. Topics share the folder of their source chat. People and Agents read and write the same files. When several people and Agents change one file at the same time, everyone's changes are kept.

The Group folder comes preinstalled with gugu. You do not install it from the market.

## Open the folder

- The folder icon, **Group folder**, in the group chat header. On the phone it sits under **More actions**.
- The **+** at the end of a group's tab row, then the folder.
- Markdown and JSON files in the chat can open directly in the folder.

## Manage files

**New** offers **New document** and **New folder**, with **Upload** beside it. When an upload has the same name as an existing file, choose **Keep both**, **Replace the old one** or **Drop the new one**.

Right-click a file (long-press on the phone) to open or download it, or choose **Copy link**, **Show in chat**, **Details**, **Rename**, **Move to…**, **Delete** or **Open with another App**. **Show in chat** jumps back to the message that sent the file.

You can filter the list by file name, sort by **Recent**, **Name** or **Size**, show only **Docs**, **Images & videos** or **Other**, and switch between **List** and **Grid**.

## Work on several files at once

Click **Select**, then tick files or use **Select all**. The bar at the bottom can **Download**, **Make temporary** or **Keep until deleted** in one go. **Show in chat** steps through the source messages one by one.

## How long files are kept

| Keep | Result |
|---|---|
| **Temporary** | The cloud copy is cleared when the period ends. The period follows the uploader's **File storage** setting under **Settings → Devices** |
| **Until deleted** | Kept until someone deletes it |

Only the person who uploaded a file can change how long it is kept.

Files in a project group can stay on the machine bound to the project and upload a copy only when someone opens them. While that machine is offline, those files open only after it is back.

## Read and write documents

Markdown documents have three views: **Read**, **Edit** and **Side by side**. Reading comes first.

While reading, hover over a block to get its menu:

- **Cite in the chat**: quotes the block, with its line numbers, into the input box.
- **Keep to cite**: notes it now so you can cite several spots together.
- **Copy a link to it**: opening the link goes straight to those lines.
- **Find in the source**: switches to the source and marks those lines.

Ticking a to-do while reading turns that line's `[ ]` into `[x]` in the source. While editing, select text to make it bold, italic, code or a link.

An empty document offers **Start writing** or **Ask an agent**. The second puts a draft request together with the file into the input box. Add what you want, then send it to an Agent.

JSON files can be viewed and changed in place. Choose **Apply** or **Discard** when done.

## Hand it to an Agent

Agents allowed to use this App can list, create, read, change and delete files in the Group folder. Name the file and the part to change.

> Please update meeting-outline.md in the group folder. Change only the second section, keep the citations, then reply to this message with the result.

You can also save a marked-up image with **Save to chat folder** in **Edit image**. See [Chat and messages](/en/chat#mark-up-an-image).
