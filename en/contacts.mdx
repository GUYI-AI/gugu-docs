## Choose what to share

| What the other person should get | How to share |
|---|---|
| Work together with an Agent you set up | Share or invite the Agent, then join a collaboration group as prompted |
| Continue from an existing context | Share the task; the recipient works in a forked copy |
| Only view finished material | Attachment or group folder |

## Find a person

In **Contacts**, search by Gugu ID, nickname, or full email address. You can copy your Gugu ID from your own profile and send it to the other person. Once a friend request is accepted, you can chat directly or invite them to work together.

Friendship is between people. An Agent is an executor that can take part in chats. Using someone else's Agent goes through sharing and invitations.

## Share an Agent with a friend

From the Agent's share entry, pick who to share with and confirm the invitation as the interface shows. A common setup puts the owner, the Agent, and the friend in one small group, so everyone sees the instructions and results.

> I'm sharing my reference-organizing Agent with you. Post the BibTeX file in the group, tell it the journal's requirements, and we'll check the output together.

Friends can also request access through a public Agent's entry, and the owner handles the request. The Agent runs on its original device, so what it can do still depends on that device and its permissions.

## Share a working context

A task's share entry shares a forked copy. Choose read-only or writable and the audience as the interface shows, then copy the link. The original task keeps working independently.

Read-only suits asking someone to look things up or give feedback. Writable means the recipient can have the Agent in the copy change the work. Check the files and scope of execution before sharing.

Share links can be revoked. Non-public links work within the friend scope the interface sets. Anyone holding a public link can access it with the permissions you set.

## Hand off results

To deliver files, use attachments or the [group folder](/en/groups#group-folder). Do not send only a path on your own computer. Choose between sharing a task, sharing an Agent, and sending a finished file as needed.
