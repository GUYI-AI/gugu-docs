---
title: "Manage tasks from your phone"
description: "Check tasks, answer questions after you leave your computer, and connect this phone's capabilities when needed."
---

The mobile app is for Android. Get the installer from the [website](https://gugu.nextmind.space). Sign in with the same account. The phone is for checking progress and sending requests; Agents still run on the original computer or server.

This page follows the phone entry points in the current Beta. What the stable release offers depends on the version you have installed.

## Find work in progress

The bottom tab **Gugu** is the personal assistant. **Projects** shows projects and tasks. **Chats** and **Contacts** are for communication, and **Me** manages your account and phone settings.

**Projects** lists tasks from every machine, grouped by project, and each group names its device. Open the one you want to continue. When a machine is offline, you can see its status and last activity. Reading the timeline, replying, and approving require it to be online. The phone never moves a task to run locally on the phone.

## View, reply, and approve

For an online task, you can view messages, tool steps, and results, plus questions and permission cards waiting for your answer. Supported engines show their own task records; unsupported ones show a notice. The phone does not show the computer's terminal.

Add a request directly and the original task continues. When the same question or permission card is open on both desktop and phone, the first answer counts. The other side shows it as already handled.

Use the mode menu in the page header to switch between the task page and a private chat with the Agent. This only changes what the phone shows, not how the computer displays it. A new task reuses the most recent choices on the target machine. Still check the engine, model, project, and permissions before sending.

## See results the Agent opened

Files or web pages the Agent opened in a task show up as attachment cards. Files are read from the original machine. Supported documents and images can be previewed, up to 20 MB per file for now.

Web pages open in the phone's browser. Addresses reachable only on that computer or its local network show a note that they can only be opened on the original machine. Files are not synced to the phone or other computers as a result.

## Give phone capabilities to the assistant

In **Me → This phone**, turn on the main switch, then connect categories one by one. Each item shows what is supported and the system permission status, for example calendar, contacts, location, notifications, SMS, recordings, and photos.

Nothing is connected by default. Turning off the main switch or disconnecting a category stops that capability immediately. Data is read only when actually used. For actions that need confirmation, such as changing calendar events, the assistant asks for your consent in chat first. If system permission is not granted, or only some photos are allowed, the assistant gets only that scope.

## Offline and notifications

The timeline needs the original machine to be online. The phone does not keep a full record you can continue from offline. Missing content fills in after reconnecting. If the connection fails, follow the prompt.

When a task finishes or needs you, the phone app can show a system banner while it is running, including when it stays in the background with permission. Notifications depend on notification and background permissions. Once the system kills the app, there is currently no separate push channel to wake it. For permission details, see [Connected apps and device capabilities](/en/integrations).

To connect another machine or server, see [Devices and remote work](/en/devices).
