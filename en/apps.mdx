An App can provide a work page, or give an Agent an extra capability, such as searching for material, opening documents or operating a browser. **Apps** in the left column has the market and the **Installed** list.

<Note>The video on this page shows the Chinese interface, with Chinese subtitles.</Note>

## Install and use

<Steps>
  <Step title="Find the App you need">Search the market by purpose or name. Open the details to see what it does, what permissions it needs, and which versions it supports.</Step>
  <Step title="Confirm capabilities and users">An install that needs permissions explains its capabilities. Follow the prompts to choose which Agents can use it. If it needs configuration or an account connection, complete that setup.</Step>
  <Step title="Open it or hand over work">Apps with a page can be opened from the left column or the task **+**. Tool Apps can be called directly by Agents allowed to use them.</Step>
</Steps>

> Use the connected calendar to sort out this week's meetings. Only list time conflicts, and don't change the schedule yet.

**Installed** only means the App is on this device. Whether it runs also depends on whether it is turned on, its Agent scope, account connections and system permissions.

Regular Apps are installed from the market as needed. The group folder is the only preinstalled App. Some official Apps belong to a first-launch default set: they are installed when a new user first launches Gugu, and can still be turned off and uninstalled. Existing users do not get them added later, and an uninstalled App is not reinstalled automatically.

## Close, quit, turn off: what's the difference

| Action | What happens |
|---|---|
| Close the tab | Hides this page. The App stays on and can be opened again |
| Move a regular App elsewhere | The same instance changes place; its existing state is kept |
| **Quit** | Hides its pages and stops background work. It starts fresh next time it opens |
| Turn off | Pauses its pages and Agent tools. Files, data and existing consents are kept |
| **Uninstall** | Removes the App and clears the data it saved. Read the prompt carefully first |

After you turn an App off or revoke a permission, the Agent's next call is checked against the new authorization. Some Apps provide a separate page for each task, such as the computer-use screen, shown separately per task.

## Updates and permissions

Check for updates in the **Installed** list. Compatible new versions update by default; you can keep the current version if needed. An update that adds permissions or changes its source asks for confirmation again. Permissions you revoked are not restored by an update.

An App's own data is stored by that App's rules. Shared files in the group folder are not the same as App private data. Check what will be cleared before uninstalling.

## Browsing the web and operating the computer

Browser Use is for web pages, and Computer Use is for the computer. An Agent can use them only after they are installed, turned on, and granted the matching permissions.
