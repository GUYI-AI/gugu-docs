Pages call gugu through `window.gugu`. Read the context first, then call what you need. Do not write `const gugu = window.gugu` at the top level of a script: it clashes with the platform's global name and the whole script stops running.

```js
window.gugu.getContext().then((context) => {
  document.documentElement.lang = context.locale || 'en';
}).catch((error) => {
  document.getElementById('status').textContent = error.message;
});
```

This page lists methods, the permissions they need and their minimum API version. Full signatures and return values are in the in-product App guides. Ask an Agent in gugu to read them topic by topic with `guide_read`; the topics are listed at the end. Manifest fields are in the [Manifest reference](/en/apps/manifest).

## Each host has its own methods

One App may run in a desktop page, a phone page, a background page or a tools program. A method a host lacks is absent from `gugu`; check with `typeof window.gugu.someMethod`.

| Host | Main differences |
| --- | --- |
| Desktop page | The fullest set: tabs, gestures, file pickers |
| Phone page | No background page, `notify`, local programs or working copies; can reach Agents on the person's computers |
| Background page | No tab or gesture: no `setTabTitle`, `clipboard` or file picker; `dispatch` must name `to` |
| Tools program | Most page methods, none that need a gesture; `linkTo` only generates links |

Any call can fail because a permission was revoked, the device went offline or a file changed. Show the failure or call `reportError`. Never hide it with an empty `.catch(() => {})` that turns failures into empty lists.

## Page context

`getContext()` returns `apiVersion`, `tabId`, `chat`, `session`, `file`, `modal`, `operator`, `locale`, `themeMode`, `capabilities` and `layout`. Optional fields depend on where the page is open.

| Field | When present |
| --- | --- |
| `chat` | A group or private chat side panel: `id`, `name`, `kind`, `groupId`, `members` |
| `session` | A task page: `id`, `agentId`, `projectId`; `root` with file permissions; `deviceId`, `deviceLabel` when on another computer |
| `file` | A page opened for a file; pass it to `files.open` |
| `operator` | Whether a person (`{ kind: 'person' }`) or an Agent works the page |
| `capabilities` | Permissions in effect now, after any revocation |
| `layout` | Display and size; `visible` says whether this page is on screen |

| Method | What it does | Condition |
| --- | --- | --- |
| `getContext` / `onContextChanged` | Current context and its changes (theme, language, visibility, size, members) | Free |
| `setTabTitle` / `setTabBadge` | Your tab's title and badge | Free |
| `onCommand` | A click on a manifest menu or toolbar entry | Free |
| `showContextMenu` | A gugu-style context menu inside the page | API 18 |
| `reportError` | Shows an error to the person and records it in the App's error log | Free |
| `openBrowserTab` | Opens an http(s) page | Free |
| `modal.open` / `modal.close` | Opens your own bundle HTML in gugu's dialog and returns its result; null when cancelled | API 11 |
| `sendToBackground` / `onBackgroundMessage` | Page to background page and back | Free |
| `broadcastToViews` / `onViewMessage` | Background page broadcasts to pages | Free |
| `linkTo` | Generates a link to a chat, file, task, project or App | API 13 |
| `openLink` | Opens such a link; in a page it needs a click or key | API 13 |
| `onLink` | Receives a link to your App | Free |
| `showMessage` / `showSession` | Jumps to a message or task after a click | Click or key |
| `clipboard.writeText` | Copies text | Click or key |
| `notify` / `onNotificationClicked` | System notifications and their clicks | `notifications` |

Pages cannot use `alert`, `confirm` or `prompt`; use `gugu.modal`. Subscriptions return an unsubscribe function. Release them when the page goes away.

## Handing something to a person or an Agent

From API 15, `gugu.dispatch(text, options)` is the one way to hand something over.

| Form | Effect | Condition |
| --- | --- | --- |
| No `to`, from a click | gugu shows its send sheet; the person can edit the text and pick the recipient; pressing send is their consent | No permission |
| `to: { chat, member }` | A private message to one member in the person's name; `visible: true` shows it to the chat | `chat:relay` |
| `to: { agent }` | Contacts an Agent | `agents:control` family |
| `to: { new: true }` with `spawn` | Starts a new Agent task; `spawn.device` to pick a computer needs API 17 | `agents:control` family |
| `draft: true` | Only fills a chat's or Agent's input box; the person decides whether to send | As above |

You can attach `refs` (links to places in files) and `images`. Failures carry the codes `not-found`, `failed`, `denied`, `rate-limited` (30 a minute per chat) or `invalid`.

<Note>
**Migrating from the old calls.** `compose`, `send`, `messageAgent` and `spawnAgent` were removed in API 15. Calling them now fails at once, and the error message names the replacement:

| Old call | Use instead |
| --- | --- |
| `compose(...)` | `dispatch(text, { draft: true, to })` or `dispatch(text, { draft: true, refs })` |
| `send(...)` | `dispatch(text, { to: { chat, member } })` |
| `messageAgent(...)` | `dispatch(text, { to: { agent } })` |
| `spawnAgent(...)` | `dispatch(prompt, { to: { new: true }, spawn })` |

After migrating, raise `apiVersion` to 15 or higher.
</Note>

## Files and live editing

Open every file with `gugu.files`. Do not keep a second copy of a group's data.

| Method | Use | Condition |
| --- | --- | --- |
| `files.open(ref)` | A live handle to a file | Free for the file the page was opened for; otherwise `files:read` or `files:write` |
| `files.list` / `search` / `recent` | Find by place, name or recent use | `files:read` |
| `files.create` / `rename` / `remove` | Create, rename, delete | `files:write` |
| `files.mkdir` / `move` | Folders and moves in a group folder | `files:write` |
| `files.upload` / `download` | Upload and download; opening a picker needs a click | `upload` needs `files:write`; several downloads at once need API 20 |
| `files.openWith` | Opens with the App the person chose or that claims the file | Click or key |
| `files.replace` / `versions` / `readVersion` | New versions and history of binary files | By file access |
| `files.onChanged` | Changes to a file list | `files:read` |
| `files.keep` | Keep a chat file's cloud copy for a while or for good | `files:write`, API 19; several files need API 20 |
| `files.viewPreferences` | Whether the chat folder shows App data files | `files:read`, API 18 |

From API 18, an App's internal state files can be created with `files.create(..., { appData: true })` or marked with `files.open(ref, { appData: true })`. The folder view hides them by default; APIs, Agents and links still reach them. Do not mark the person's own documents.

A text handle offers `text`, `edit`, `insert`, `delete`, `onChange`, `snapshot` and `applyFrom`. Bind an input or editor with `gugu.bind.text` so several people typing at once keep their letters. For CodeMirror, use the library from `gugu.codemirror()` and bind it with `gugu.bind.codemirror`.

A JSON file is read and written field by field through `f.data`. `f.transact` groups one operation, and `f.toJSON()` gives a plain copy. Text fields several people type in are created with `gugu.text('')` and edited through `f.textAt([...])`. Cursors, drags and game frames go in `f.presence`; only results that must stay go in the file.

Show connection, save and refusal states with `f.status`, `f.saved`, `f.onStatus` and `f.onRefused`. Release a handle with `f.close()`.

## Agents, programs and data

| Method | What it does | Condition |
| --- | --- | --- |
| `getAppState` / `onAppStateChanged` | Window focus, current task, each pane's tab | Free; some fields need the matching permission |
| `listAgents` / `onAgentsChanged` | Visible Agents and their status | `agents:read` family |
| `readAgentHistory(agentId, before)` | Conversation pages; the start is reached when `nextCursor` is null | `agents:history` family, this computer only |
| `stopAgent` | Stops an Agent on this computer; work already done stays done | `agents:control` family |
| `sessions.index` / `sessions.read` | External command-line sessions: list, conversation and loaded context | `agents:history:all`, API 17 |
| `callProgram` / `onProgramNotification` | Call your own program and hear its notifications; the `device` option needs API 17 | While `agents:tools` is granted |
| `readData` / `writeData` / `listData` | The App's private data folder, up to 8 MB per file; removed on uninstall | Free |
| `projection.mount` | Shows a picture your program publishes in a task page and passes input back | `agents:tools`, API 22, desktop |

Live counters that cannot be read in `listAgents` are `null`, never zero. An empty page from `readAgentHistory` may still carry a `nextCursor`; keep paging. Starting and contacting Agents spends the person's quota, so do not wake them in a loop.

There are two ways to give Agents tools: each export of `tools.js` is one tool, or the manifest declares a local program. Agents see the tool as `<App id>__<tool>`. Programs run with the person's local rights; the page sandbox does not apply to them. From API 21, a tool's `run` receives an abort `signal`; pass it to long-running work.

From API 22, a tools program can publish a local picture with `gugu.projection.create(driver)` (PNG, JPEG or WebP, at most 512 KiB decoded per picture), and a task page of the same App shows it and passes input back with `gugu.projection.mount`. Pictures travel only on this computer.

## Chats and forum

`chat:read` (API 6) provides `gugu.chats.list`, `chats.members`, `messages.history` and `messages.search`. Results carry `messages` and `next`; pass `next` as `before` to page until it is `null`. Only content the caller may see is returned.

`gugu.forum` (API 9) provides list, read, post, reply, react, remove, block, assign, award and onChanged. Reading needs no permission; writing needs a click. Credits and assigning Agents go through gugu's own confirmation. `confirming: true` means confirmation is still open; subscribe to events and read the result again.
