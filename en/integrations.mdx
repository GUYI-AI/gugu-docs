Before connecting an app, decide where the material is, which account to use, and how far you want the Agent to go.

## Find the connection you need

| Situation | Where to fix it |
|---|---|
| A model needs a provider account or API connection | **Settings → Subscriptions** |
| The Agent needs an account service such as a calendar, documents, or maps | **Settings → Gugu → Connected apps**, or **Library → Integrations** |
| An App is not enabled, or not allowed for this Agent | **App → Installed** |
| You want this computer's calendar, mail, or computer control | **Settings → Devices → What this computer can do** |
| You want calendar, SMS, or photos on your phone | **Me → Permissions** on the phone |
| The system has not allowed notifications or file access | **Settings → Permissions** |

## Connect a service

Open **Settings → Gugu → Connected apps**. You can also get there from the **Library** and from the relevant App's settings. Choose a service, then authorize it in the browser or fill in the setup as the page asks.

> From my connected calendar, put together this week's schedule and mark time conflicts. Don't change any events yet.

The connection status should show **Connected**. If the authorization expires, authorize again and retry the work. After an external service connection changes, a regular task that is already running may need to be reopened. Disabling an App or revoking its permission takes effect on the next call.

The services you can connect are those in the current list. Different apps may need browser authorization, an account sign-in, or a key. Follow the prompts you see.

### Connect with your own key

Some services need a key you apply for yourself, such as **AMap**. On the AMap open platform, create an app and add a free key with the service type "Web 服务" (Web service), then paste it into **AMap Web service key**. The gugu platform keeps the key for you, so all your devices can use the connection.

## Let an Agent use it

When you install and authorize an App, you can choose which Agents use it. Even after an app is connected, check that the current Agent is allowed to use it.

Connect only the capabilities you need. Calendar connections, model subscriptions, and computer control require separate authorization. A successful model sign-in does not complete these authorizations.

## Actions on your computer

In **Settings → Devices → What this computer can do**, connect **Computer control**. On a Mac, also turn on Accessibility and Screen Recording in System Settings when prompted.

While the Agent works, a tag on the top edge of the target window names who is in control. Click **Stop** at any time.

If something must be confirmed before it is sent or submitted, say so in the task:

> Draft a reply and fill it in. Stop before sending.

## Capabilities on your phone

On Android, once the matching system permissions are granted, the phone can provide SMS, recordings, photos, and similar data. These permissions are only for task Agents on that phone; see [Mobile](/en/mobile#phone-permissions) to set them up. Grant only what this job needs.

If something fails, check that the target device is online, the app is enabled, and the system permission is granted, then continue the original task.
