---
title: "Connected apps and device capabilities"
description: "Let Agents use your existing accounts and the capabilities your computer and phone have already authorized."
---

Before connecting an app, decide where the material is, which account to use, and how far you want the Agent to go.

## First, find which part is not connected

| Situation | Where to fix it |
|---|---|
| A model needs a provider account or API connection | **Settings → Subscriptions** |
| The Agent needs to read a service such as a calendar or documents | **Connected apps** in the assistant's profile, or **Library → Integrations** |
| An App is not enabled, or not allowed for this Agent | **App → Installed** |
| The system has not allowed notifications or file access | **Settings → Permissions**; for computer control, use Computer Use's own settings |

## Connect a service

Find **Connected apps** in the personal assistant's profile. You can also get there from the **Library** and from the relevant App's settings. Choose a service, then authorize it in the browser or finish setup as the page asks.

> From my connected calendar, put together this week's schedule and mark time conflicts. Don't change any events yet.

The connection status should show **Connected**. If the account expires, authorize again and retry the work. After an external service connection changes, a regular task that is already running may need to be reopened. Disabling an App or revoking its permission takes effect on the next call.

The services you can connect are those in the current list. Different apps may need browser authorization, an account sign-in, or API setup. Follow the prompts you see.

## Let an Agent use it

When you install and authorize an App, you can choose which Agents use it. Even after an app is connected, check that the current Agent is within the allowed range.

Connect only the capabilities you need. Calendar connections, model subscriptions, and computer control each cover their own capability. A successful model sign-in does not complete these authorizations.

## Actions on your computer

After enabling Computer Use, grant the system permissions it asks for in its settings. While the Agent works, you can open the **Computer** page next to the task.

If something must be confirmed before it is sent or submitted, say so in the task:

> Draft a reply and fill it in. Stop before sending.

## Capabilities on your phone

On Android, once the matching system permissions are granted, Gugu can read SMS, recordings, photos, and similar data. Available items appear in the device capabilities. Grant only what this job needs.

The device must stay connected. If something fails, check the target device, whether the app is enabled, and the system permissions, then continue the original task.
