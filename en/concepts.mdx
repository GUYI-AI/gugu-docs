Say you are preparing a group meeting. The material is on your computer. You organize the literature first, then write an outline, and finally check it with your classmates. Here is how each part of gugu helps.

| Name | How it is used for one group meeting |
|---|---|
| Personal assistant | Remembers that the outline stays to one page, arranges for the material to be organized and follows up |
| Agent | The worker that reads files and writes the outline for you, using an engine such as Codex or Claude Code |
| Model | Provides the reasoning for the work, using your provider account or gugu credits |
| Task | Keeps the requirements, process and results of this one piece of work, "Organize meeting literature" |
| Project | Keeps the papers, experiments, drafts and tasks for one research topic together |
| Folders and devices | Identify where the material is stored, for example the papers folder on your laptop |
| Group | Where people and Agents discuss and hand over results. Each project has a project group that holds only you and your Agents; to check the outline with classmates, start a group chat in **Chats** |
| Topic | Opens a focused discussion from one message in a group, for example revising the third figure on its own |


## A task can stand on its own

To tidy up a set of notes once, create a task directly; you do not need a project first. When you keep producing work from the same material, put the related folders and tasks into a project.

A project can span folders and devices. A task still runs on one chosen device. Choosing several devices for a project's scope does not copy the same task to each machine.

## Each task also has an Agent you can mention

The task title is for finding the work; the Agent name is for mentioning it in chat. A task's Agent can join the project group, so you do not need to create another identical worker.

The personal assistant greets you in its own chat; the workers it sends out appear in tasks. Open a worker to chat with it directly while you keep asking the personal assistant about other things.

## Projects share context; files stay where they are

Add a folder from another machine to the same project, and your Agents on different devices can pass work along on the same thing. The file contents still stay on their own devices.

A project group holds only you and your Agents. To work with other people, start a group chat on the **Chats** tab in **Messages**, and bring in the people and the Agents you need.

To review a finished result together, send it as an attachment or put it in the [group folder](/en/folder). To keep working, open the original task. To have another Agent take over, give it the goal, the conclusions already confirmed and where to deliver.
