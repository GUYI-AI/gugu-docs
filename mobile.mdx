---
title: "用手机看管任务"
description: "离开电脑后查看任务、回答提问，也可以让这台手机自己运行任务。"
---

手机端为 Android，可从[官网](https://gugu.nextmind.space)获取安装包。用同一账号登录后，可以查看和回复电脑或服务器上的任务。启用手机 Agent 后，手机也能自己运行任务。

<Note>本页按当前 Beta 的手机界面整理。正式版可用范围以当前安装版本为准。</Note>

## 找到入口

底栏只有两格：「消息」和「伙伴」。

- 开通了个人助理时，「消息」第一行就是咕咕。
- 「伙伴」里的「项目 · N」分区列出项目。打开项目，查看各台机器上的任务。
- 「消息」或「伙伴」页头左上角的头像打开「我的」，在这里管理账号和手机设置。

机器离线时可以看到状态和最后在线时间。读取时间线、回复和批准需要那台机器在线。

## 查看、回复和批准

在线任务可查看消息、工具过程、结果，以及等待你回答的提问和权限卡片。支持的引擎会显示自己的任务记录，不支持时会提示「这里看不了内容」。

直接补充要求，原任务就会继续。

## 看 Agent 打开的结果

Agent 已在任务里打开的文件或网页会显示为附件卡。文件从原机器读取，可以预览支持的文档和图片，单份文件预览上限为 20 MB。

网页交给手机浏览器。只在那台电脑本机或内网能访问的地址，会提示「只能在那台电脑上打开」。文件没有因此自动同步到手机或其他电脑。

## 让手机自己运行任务

1. 打开「我的 → 这台手机」，在「手机任务」点「启用手机 Agent」。
2. 状态显示「可处理任务」后，新建任务时在选项里选「手机 Agent」。项目页没有可用机器时，也可以点「设置这台手机」完成同样的设置。
3. 手机任务使用咕咕提供的模型。
4. 不再需要时，点「停止手机 Agent」。启动失败时点「重新启动」。

手机任务的记录保存在这台手机上。任务进行中 App 可以切到后台继续，系统强行结束 App 时，执行中的那一轮会标为中断，不会自动重做。

### 给任务配置 Skill

手机任务页有「配置 Skill」按钮。每个任务可以单独添加 Skill，写清楚做事的方法，也可以「导入 SKILL.md」。每个任务最多 20 项，可以逐项启用或停用。

任务运行或等你确认时不能修改。保存后从下一轮开始生效。Skill 只说明怎样使用已有工具，不会增加手机权限。

## 手机权限

打开「我的 → 权限」，或在「这台手机」点「权限」。页面分两组：

- 「咕咕」：App 自己需要的系统权限，例如通知和后台运行。
- 「这台手机上的任务 Agent 能用」：日历、通讯录、定位、通知读取、勿扰、闹钟、健康、短信、录音、照片。

第二组仅这台手机上的任务 Agent 可使用。点一项按提示授权，状态显示「已开启」或「未开启」。系统只授权部分照片时，按实际范围读取。

改日程、开关勿扰、取位置之前，Agent 会先问你。健康数据从 Health Connect 只读读取。设闹钟需要咕咕在前台。

## 离线与提醒

电脑上的任务，时间线要从原机器实时读取。那台机器离线时读不到，重连后补齐。

任务完成或等你处理时，手机 App 运行期间可发系统横幅，包括按权限保持后台运行时。提醒受通知和后台权限影响，可在「我的 → 权限」检查。

连接另一台机器或 server，见[设备与远程工作](/devices)。
