title: "连接应用与设备能力"
description: "让 Agent 使用已有账号，以及电脑和手机已经授权的能力。"

连接应用之前，先确定资料在哪、要用哪个账号，以及希望 Agent 做到哪一步。

## 先分清是哪一项没连上

| 情况 | 去哪里处理 |
|---|---|
| 模型需要厂商账号或 API 连接 | 设置 → 订阅 |
| Agent 要用日历、文档、地图等账号服务 | 「设置 → 咕咕 → 连接应用」，或资源库 → 集成 |
| 某 App 未启用、没给这位 Agent 使用 | App → 已安装 |
| 要用这台电脑的日历、邮件或电脑控制 | 设置 → 设备 → 这台电脑能做的事 |
| 要用手机里的日程、短信、照片 | 手机「我的 → 权限」 |
| 系统没有允许通知或文件访问 | 设置 → 权限 |

## 连接一个服务

打开「设置 → 咕咕 → 连接应用」，也可以从资源库和相应 App 的设置进入。选择服务，按页面要求在浏览器授权或填写配置。

> 从我已连接的日历整理本周安排，标出时间冲突，先别修改任何日程。

连接状态应显示为已连接。账号失效时重新授权，再重试刚才的工作。外部服务连接改变后，已经运行的普通任务可能需要重新打开。App 停用或收回权限，会在下一次调用时生效。

可连接的服务以当前列表为准。不同应用可能要求浏览器授权、账号登录或填写 Key，按实际提示操作。

### 用自己的 Key 连接

有的服务要用你自己申请的 Key，例如「高德地图」。在高德开放平台免费创建应用并添加 Key，服务平台选「Web 服务」，再粘贴到「高德 Web 服务 Key」。Key 由咕咕平台代为保管，你的各台设备都能用上这次连接。

## 给 Agent 使用

App 安装与授权时可指定使用的 Agent。一个应用连上了，仍需确认当前执行者在允许范围内。

需要哪项能力就连接哪项。日历连接、模型订阅和电脑控制各管自己的能力，模型登录成功不会自动完成这些授权。

## 电脑上的操作

在「设置 → 设备 → 这台电脑能做的事」连接「电脑控制」。Mac 上还要按提示在系统设置里打开辅助功能与屏幕录制。

Agent 操作时，目标窗口顶边会出现标签，写明谁在操作，可随时点「停止」。

对外发送或提交前需要确认的，在任务里说清楚：

> 帮我起草回复并填入，停在发送前。

## 手机上的能力

Android 获得对应系统权限后，可提供短信、录音、照片等读取能力。这些权限只给这台手机上的任务 Agent 使用，设置方法见[手机端](/mobile#手机权限)。只授权本次需要的部分。

失败时先检查目标设备是否在线、应用是否启用、系统权限是否已给，再继续原任务。
